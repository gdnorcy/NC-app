配置结构升级（theme_config 新 Schema）

"bgType": "gradient" // solid / gradient / glass / paper
"bgStart": "#0e2a4e", "bgEnd": "#3b7bd4", "bgAngle": 160
"textColor": "#ffffff", "text2Color": "rgba(255,255,255,.85)"
"accent": "#7cc0ff" // 点缀色
"fontFamily": "serif" // sans 黑体 / serif 衬线
"border": "gold", "borderColor": "#c9a25e" // none/gold/glow
"texture": "spots" // none/spots/grid/dots
"radius": 18, "barTop": false // 顶部渐变条（E）
"cardStyle": "solid" // solid / glass（H 毛玻璃）
// 旧模板只有 primary/background/radius → 自动降级兼容

落地实施步骤

  • DB：card_templates 表插入 6 个新模板（enabled=1），theme_config 用新 Schema；清理 2 个测试模板
  • 渲染升级：写统一 `renderTemplateTheme(theme)`，名片详情/分享/会员中心等所有展示点支持 渐变/字体/描边/纹理/毛玻璃
  • 创建页：模板区改横向滑动列表，缩略图直接渲染「迷你名片卡」真实效果，选中实时换肤
  • templateSelect 页：缩略图样式与创建页统一
  • 三端实测：H5 + 微信小程序端渲染一致（毛玻璃在小程序降级为半透明实色）

注意事项

① 渲染升级影响所有名片展示点 → 必须向后兼容（旧模板 primary 兜底）② 小程序对 backdrop-filter（毛玻璃）支持有限 → H 模板小程序端降级处理 ③ 模板选择"横滑"替代原来 3 个并排，需保留付费模板的展示位（当前全免费）
