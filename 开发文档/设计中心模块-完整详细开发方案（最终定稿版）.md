# 设计中心模块-完整详细开发方案（最终定稿版）
> 项目：平台型智能名片SaaS系统
> 模块：设计中心（含素材中心）
> 底层依赖：系统统一多租户底座、租户隔离、权限体系、对象存储
> 文档版本：V1.0 最终定稿
> 文档用途：产品评审、前端开发、后端开发、测试基准
> 说明：本模块属于【租户后台】功能，归属单个租户，所有配置、素材数据绑定 tenant_id，租户之间完全隔离。

## 一、模块概述
### 1.1 模块定位
设计中心属于**租户后台核心可视化装修模块**。租户（购买SaaS服务的客户项目）管理员/授权子账号，可在设计中心对微信名片小程序进行可视化页面装修、全局样式配置、底部导航管理、素材资源管理、页面模板管理。
租户内支持企业员工、个人用户入驻创建名片；租户级素材库、页面模板，租户内所有名片页面可以复用。

### 1.2 子功能清单
1. 页面装修：可视化拖拽编辑器，支持编辑首页、个人名片页、个人动态页
2. 系统风格：全局主题色、圆角、按钮样式、页面背景统一配置
3. 底部导航：小程序Tab菜单新增、编辑、复制方案、启用/禁用、设置默认导航
4. 系统模板：平台公共模板市场、租户私有模板；模板一键应用、导入导出
5. 首页跳转：设置小程序启动默认页面
6. 个人中心装修：个人名片中心DIY页面配置
7. 素材中心：租户独立素材库，图片上传、分类管理、预览、移动、删除；全局弹窗组件ImageSelect素材选择器

### 1.3 底层约束规则
1. 租户数据隔离：所有装修配置、素材资源绑定 `tenant_id`，跨租户不可查询、不可访问。
2. 权限体系：依托系统RBAC权限底座，设计中心各项功能权限在租户后台子账号权限面板配置。
3. 文件存储：素材文件复用系统统一对象存储服务；上传鉴权、文件大小限制、格式白名单、CDN访问地址。
4. 缓存机制：页面配置、模板数据存入Redis；发生保存/发布操作时，自动清理当前租户对应缓存，小程序端实时加载最新配置。
5. 安全规则：素材删除有引用校验；发布操作保留历史版本记录（MVP只保留最近3个版本）。

## 二、角色与权限设计
> 权限Key统一在系统权限枚举维护；权限面板位置：租户后台 → 系统设置 → 子账号权限
### 2.1 设计中心基础权限
| 权限名称 | 权限Key | 权限说明 |
| ---- | ---- | ---- |
| 设计中心：查看模块 | design:view | 进入设计中心菜单，查看全部子模块入口（基础权限） |
| 页面装修：编辑/保存/发布 | design:page | 可视化编辑器操作，保存草稿、发布页面、查看历史版本 |
| 底部导航：管理 | design:tab | 新增、编辑、复制、启用、删除导航方案 |
| 系统风格：配置 | design:style | 修改全局样式配置 |
| 系统模板：管理 | design:template | 模板导入、导出、一键应用模板 |
| 首页跳转：配置 | design:homeJump | 修改小程序默认首页 |
| 个人中心装修：编辑 | design:mine | 个人名片中心页面DIY配置 |

### 2.2 素材中心细粒度权限
| 权限名称 | 权限Key | 权限说明 |
| ---- | ---- | ---- |
| 素材：查看素材库 | media:view | 素材中心页面、素材选择弹窗访问基础权限 |
| 素材：上传素材 | media:upload | 单文件/批量上传图片素材 |
| 素材：分类管理 | media:category | 素材分类新增、重命名、删除 |
| 素材：移动素材 | media:move | 素材跨分类移动 |
| 素材：删除素材 | media:delete | 删除素材、批量清理闲置素材 |
| 素材：复制CDN链接 | media:copyUrl | 获取素材CDN访问地址 |

> 权限联动规则
> 1. `design:view`为设计中心基础权限，取消勾选后，设计中心所有子权限置灰不可启用。
> 2. `media:view`为素材中心基础权限，关闭后素材页面、素材选择弹窗都无法打开。
> 3. 前端：`v-permission`指令控制按钮显隐；后端：AOP注解`@RequirePermission("xxx")`强制鉴权拦截，前端隐藏按钮不能绕过后端校验。

## 三、页面原型与交互设计
### 3.1 设计中心首页（模块入口页）
页面路径：租户后台 → 设计中心
- 布局：功能卡片列表，卡片对应子模块：页面装修、系统风格、底部导航、素材中心、系统模板、首页跳转、个人中心装修
- 交互：点击卡片跳转对应子页面；没有权限的卡片自动隐藏；页面顶部面包屑导航。

### 3.2 页面装修编辑器（核心页面）
页面路径：设计中心 → 页面装修
布局分为三栏：
1. 左侧栏：页面列表（首页、名片详情页、个人动态页），可切换编辑不同页面；显示草稿/已发布标记。
2. 中间栏：小程序预览画布（手机模拟器，自动适配手机安全区，规避刘海状态栏遮挡内容）；画布支持缩放。
3. 右侧栏：上方组件库面板，下方属性配置面板。

> 内置可拖拽组件清单：
> 图片组件、文本组件、按钮组件、视频组件（支持视频号视频嵌入）、名片交换组件、个人动态组件、访客雷达组件、分割线、空白占位组件。

**交互规则：**
1. 拖拽：从组件库拖入画布，新增组件实例；点击画布组件选中，右侧自动加载对应属性表单。
2. 组件操作：选中组件支持复制、删除、上下移动层级。
3. 撤销/重做：编辑器内本地缓存操作记录。
4. 保存草稿：仅保存至租户后台，小程序端不会生效，可多次保存。
5. 发布页面：将草稿版本提升为线上生效版本；自动记录版本号、操作人、操作时间；保留最近3条历史版本，支持回滚。
6. 校验规则：发布时校验页面配置JSON结构合法性。

### 3.3 系统风格配置页
页面路径：设计中心 → 系统风格
配置项：
- 主色调、辅助色、正文文字颜色、次要文字颜色
- 全局圆角尺寸（卡片圆角、按钮圆角）
- 按钮默认样式（填充/描边）
- 页面背景色 / 背景图（点击唤起素材选择弹窗选择图片）
保存后全局生效，作用于当前租户下全部小程序名片页面。

### 3.4 底部导航配置页
页面路径：设计中心 → 底部导航
- 多方案管理：租户可创建多套导航方案，支持设置其中一套为**默认方案**，小程序读取默认方案渲染Tab。
- 导航项配置：文字、未选中图标、选中图标（唤起素材选择弹窗）、跳转页面地址。
- 操作：新增导航方案、编辑、复制方案、删除方案。
> 约束：正在作为默认方案的导航方案不允许删除。

### 3.5 系统模板页面
页面路径：设计中心 → 系统模板
分为两个Tab：模板市场、我的模板
1. 模板市场：平台公共预设模板列表，卡片预览；点击【应用模板】，用模板配置覆盖当前租户页面、风格、导航配置，弹窗二次确认。
2. 我的模板：租户另存为的私有模板；支持导出模板包（JSON配置文件，仅保存素材引用地址，不打包素材文件）；支持导入外部模板JSON文件。

### 3.6 素材中心页面（重点模块）
页面路径：设计中心 → 素材中心
页面布局：
1. 左侧：素材分类树，默认内置「全部素材」「未分类」；支持用户新建自定义分类（一期仅支持一级分类，不支持子分类）。
2. 右上：操作按钮区【上传素材】【新建分类】【批量操作下拉】。
3. 主体区域：素材卡片网格，卡片展示缩略图、文件名、文件大小、创建时间；hover悬浮弹出操作菜单：预览、移动分类、复制链接、删除。
4. 筛选功能：素材名称搜索、上传时间筛选。
5. 批量操作：批量移动素材、批量删除闲置素材。

#### 素材引用追踪逻辑
素材会记录被页面、导航、系统风格引用关系；标记素材状态：【已被引用】/【闲置】
- 已被引用素材：禁止删除，删除按钮置灰；提示：该素材正在被页面/导航使用，无法删除。
- 闲置素材：可删除。

#### 素材选择弹窗 ImageSelect（全局复用组件）
唤起场景：页面编辑器、导航图标、系统背景图等所有需要选择图片的地方
- 弹窗布局：左侧分类列表，右侧素材网格；支持搜索、上传素材。
- 交互：单选素材，选中后返回素材CDN地址；弹窗内**不提供素材删除、分类管理功能**。
- 权限联动：无`media:view`权限时弹窗提示「暂无素材查看权限」；无`media:upload`时上传按钮置灰禁用。

### 3.7 首页跳转、个人中心装修页面
1. 首页跳转：下拉选择小程序页面，设置小程序启动默认页面。
2. 个人中心装修：可视化DIY个人名片中心页面，编辑器能力同页面装修。

## 四、核心业务流程
### 流程1：页面编辑 & 发布流程
1. 租户子账号进入页面装修 → 选择页面
2. 拖拽组件、修改组件属性 → 保存草稿
3. 预览效果确认 → 点击发布
4. 后端校验配置，保存新版本，清理Redis缓存
5. 小程序端加载最新发布配置
6. 如需回滚：进入历史版本，选择版本回滚，自动发布选中版本

### 流程2：素材上传与使用流程
1. 进入素材中心 / 在编辑器唤起素材弹窗
2. 选择本地图片上传；后端校验文件格式、大小，上传对象存储，写入素材表
3. 素材存入当前租户素材库
4. 在编辑器/导航配置选中素材，保存引用关系
5. 删除素材时：先校验引用关系，被引用素材禁止删除

### 流程3：模板应用流程
1. 在模板市场选择模板，点击应用模板
2. 弹窗提醒：应用模板会覆盖当前页面、风格、导航配置，确认继续？
3. 确认后，模板JSON写入租户装修配置，自动发布，清理缓存

八、测试要点
租户隔离：A 租户的页面配置、素材、模板，B 租户完全不可见。
权限校验：无对应权限账号，菜单隐藏；直接调用接口返回无权限。
素材引用校验：被页面使用的素材不能删除。
版本能力：发布后可以回滚历史版本。
缓存验证：发布后小程序端立刻读取最新配置。
导航方案校验：默认导航方案禁止删除。
编辑器健壮性：非法 JSON 配置提交后端拦截。
九、非功能需求
