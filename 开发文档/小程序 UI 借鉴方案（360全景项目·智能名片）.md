# 小程序 UI 借鉴方案（360全景项目·智能名片）

# 方案概述

**核心判断：**参考产品 UI 的“好看 \+ 精细”来自三件事——一套原子化设计系统（app\.wxss）、30\+ 个公共组件、以及名片首页的精妙信息架构。本方案把这三层转译到自研版（360全景项目，uni\-app / Vue），并落到具体文件。

借鉴的是**设计语言与组件模式**，不是代码搬运（参考产品为微信小程序原生 WXML，自研为 uni\-app）。方案只描述设计与落点，未改代码。

## 读者任务与范围

|读者任务|方案回答|
|---|---|
|借鉴什么|三层：设计系统（字号/色板/间距/1px 线/栅格）、组件库、名片首页信息架构。|
|落到哪|自研版 web\-app：新建 styles/ 工具类、components/ 补组件、重构 cardDetail\.vue。|
|怎么做|先打底设计 token，再补组件，最后改名片页；对齐现有品牌蓝/橙与中性灰。|
|不做什么|不复制参考产品视觉到“换皮”；不改变现有功能与数据；不搬参考产品商城/全景 UI。|

## 自研版现有 UI 基线（对齐点）

借鉴必须落在现有语言之上，先确认已有能力：

- **沉浸式 hero**：cardDetail\.vue 品牌色渐变（默认橙 \#b45309→\#f59e0b），hero\-badge 会员徽章。

- **图标库**：SIcon 公共组件（自带图标集，mobile/exchange/location/channel/radar/star 等）。

- **快捷栏 / Tab / 底部 TabBar**：quickbar、mp\-tabs、底部名片/雷达/集市/会员 Tab。

- **中性灰底**：页面背景 \#f5f6f7，次级图标 \#86909c，品牌蓝 \#165dff。

- **线索表单**：访客表单已内嵌名片页（线索回流）。

# 六、风险与待确认

- **不换皮**：借鉴设计系统与信息架构，保持自研品牌蓝/橙主色，不整套复制参考产品绿色主题。

- **数据对齐**：头像墙 / 语音卡 / 多模板依赖现有 card 数据字段，需核对 visitors / voice / template 数据是否齐备。

- **小程序端适配**：uni\-app 新组件需同时验证 H5 与小程序端渲染，尤其 Canvas 海报。

- **范围**：本方案只覆盖 C 端名片域 UI，管理端 web\-admin 与全景 / 商城不在借鉴范围。

# 七、名片模板布局借鉴

**关键结论：**参考产品名片“布局”不在后端，在后端只有模板元数据；真正的布局在小程序端多个具名模板里，通过 **ta\-tp\{\{now\_temp\_id\}\}** 动态切换。借鉴的关键是“后端管元数据、前端按模板 id 切换布局”这套结构。

## 7\.1 后端只有元数据，布局在前端模板

后端表 longbing\_tp\_mingpian\_template 仅存 name（模板名）、path（缩略图附件）、price（原价）、group（分组）、status、user\_vip\_discount（是否用 VIP 折扣），后台 admin 只做增删改查，不存任何布局或样式代码。

## 7\.2 两套模板布局结构（wxapp/templates/card\-tp\.wxml）

|模板|布局结构|交互/细节|
|---|---|---|
|tp1 卡片头式|顶部头像大图 → 姓名 \+ VIP 徽章 → 职位 → 公司名 \+ 公司 logo，居中头部卡片|VIP 态显徽章，非 VIP 显“去开通”入口|
|tp2 全屏大图式|头像做全屏背景（translateY 随滚动、opacity 渐变）→ 白色信息区 → 姓名大字 \+ VIP → 公司 / 电话 / 地址三行（未填则“去完善”）→ 人气 / 收藏 / 点赞三格计数条|收藏 / 点赞可点击，icon 实心态切换|

两种模板各自有 my\-（自己看）与 ta\-（他人看）两套视角，样式经公共 wxss @import 提供（card1\-head\-box / card2\-img\-box / card2\-line）。

## 7\.3 自研版落地建议

- **后端管元数据**：名片模板表只管 name / 缩略图 / price / group，与现有 card\.templateTheme 数据打通。

- **前端按 id 切换**：cardDetail\.vue 用 templateTheme/nowTempId 切换多套布局组件，对齐参考端 ta\-tp\{\{id\}\}。

- **先落两套布局**：卡片头式（信息聚焦）\+ 全屏大图式（视觉冲击），覆盖主要名片场景。

- **视角区分**：自己预览（my\-）与他人浏览（ta\-）用同一布局、差异仅在交互（收藏/点赞实心态）。
