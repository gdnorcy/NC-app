# 微信开发者工具上传小程序操作步骤

> 面向当前项目：`web-app/dist/build/mp-weixin`
> 2026-10-21

---

## 一、开始前先确认三件事

| 检查项 | 怎么查 | 不对会怎样 |
|---|---|---|
| 服务器已是最新代码 | 见文末「部署自检」 | 装修入口、支付都还是旧的 |
| 小程序后台已配 AppID/AppSecret | 客户后台 → 全端渠道 → 微信小程序 | 真机登录会每次建新用户（mock 通道） |
| 开发者工具已登录**有该小程序开发权限**的微信号 | 工具右上角头像 | 上传报「无权限」 |

> ⚠️ 工具里要用**「小程序」项目类型**，不是「公众号」。项目目录选
> `web-app/dist/build/mp-weixin`，工具会自动读里面的 `project.config.json`。

---

## 二、导入项目

1. 打开**微信开发者工具** → 右上角「+」→ **导入项目**
2. **目录**：选到 `web-app/dist/build/mp-weixin`
   （注意是 `dist/build` 下那层，不是 `web-app` 根目录）
3. **AppID**：填 `web-app/src/manifest.json` 里 `mp-weixin.appid` 的值
4. 后端服务 → 「不使用云服务」→ 确定

导入后应能看到 `pages/cardMain/`、`pages/card/`、`pages/mall/` 等分包目录。

---

## 三、先本地预览（必做，别直接上传）

工具右上角 **预览** → 微信扫码进真机。

真机上依次确认：

- [ ] 登录后名片区正常（不是空白）
- [ ] 「我的名片」页有**「装修我的名片」**入口 ← 这是你之前反馈找不到的那个
- [ ] 进装修页能拖组件、保存后名片页生效
- [ ] 后台「名片管理」能看到小程序里新建的名片（如「林平」）
- [ ] 会员购买页点支付：若已配真实商户号会调起微信支付；
      未配则会提示「未配置真实微信支付…模拟支付」

> 🔴 **真机登录必须是真实 openid**。库里现有的 `rebuild_openid_*` 是清库重建时造的假数据，
> 真实支付必须先在真机完成一次登录（用真实 AppID + AppSecret）才能产生真 openid。

---

## 四、上传

1. 工具右上角 **上传**（不是「提交审核」，先只上传）
2. **版本号**：`1.0.0` → 之后递增（微信要求比上次高，如 `1.0.1`）
3. **项目备注**：写清本次内容，例如
   `名片装修入口与模板购买支付改造`
4. 确定 → 等待上传完成（会显示「上传代码成功」）

上传后代码进入**开发版本**，还在你账号里，未生效。

---

## 五、提交审核 → 发布

1. 打开 [微信公众平台](https://mp.weixin.qq.com) → 左侧「管理」→「版本管理」
2. 在**开发版本**卡片上点「提交审核」
3. 填写：
   - **服务类目**：按实际业务选（如「工具-办公」或「商业服务」）
     ⚠️ 类目选错会被驳回，且影响支付能力开通
   - **审核备注**：写明功能（如「企业名片展示与会员购买」）
   - **测试账号**：如需登录，提供微信号 + 密码
4. 审核通过后，在同一页面点 **「发布」** → 小程序生效

> 🔴 **支付相关改动要特别注意**：若这次改动涉及付费功能，
> 需确认「微信支付」权限已开通且类目与经营内容匹配，否则真机支付会失败。
> 审核期间建议先别提交支付页面的改动，等资质齐了再上。

---

## 六、验证发布结果

发布后重新扫码进入，**必须重新进入**（微信有版本缓存）：

1. 小程序右上角「…」→「重新进入小程序」可强制拉最新版本
2. 必要时在开发者工具点「清缓存 → 全部清除」再预览

---

## 七、部署自检（上传前先确认服务器已更新）

```bash
# 服务器当前 HEAD 应该是 deploy 最新
cd /opt/app && git log --oneline -1

# 服务是否 active
systemctl is-active panorama

# 新接口是否已上线（未配支付时 /notify 应返回 401/403，不是 404）
curl -s -o /dev/null -w "%{http_code}" -X POST \
  https://你的域名/api/payment/notify/wechat \
  -H 'Content-Type: application/json' -d '{}'
# 期望：401（验签失败）说明路由在；404 说明代码没更新
```

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 扫码后还是旧功能 | 微信版本缓存 | 工具「清缓存→全部清除」后重新预览；或真机右上角「重新进入小程序」 |
| 真机登录后提示未开通/资料丢失 | AppID/AppSecret 未配，走 mock 通道 | 后台配好后重新登录 |
| 上传报「无权限」 | 当前微信号不是该小程序成员 | 公众平台 →「成员管理」添加开发者 |
| 支付报「未获取到付款人 openid」 | 该用户 openid 是 mock/fake | 真机重新登录产生真实 openid |
| 支付报「配置不完整」 | 后台支付配置缺项 | 见《微信参数与支付配置说明》第二节 |
| 提交审核被驳回「类目不符」 | 类目选错 | 改类目或调整功能描述 |
