# 一、V1 落地实现（代码）

> 原稿（2026-10-20 早）给的是原生小程序示例代码（`Page()`/`wx.request`/rpx）与旧字段
> （`feedToken`）。项目移动端实际是 **uni-app Vue3**（`web-app/src/pages/card/*.vue`），
> 组件体系是 `web-admin` 的 `componentRegistry.js`。V1 按真实体系落地，差异点见
> 「与原稿的差异」一节。

## 1.1 页面与文件清单

| 文件 | 职责 |
| ---- | ---- |
| `web-app/src/pages/card/cardEdit.vue` | 装修编辑页（列表/增删/排序/配置弹窗/整存保存） |
| `web-app/src/utils/cardCompRegistry.js` | 移动端轻量组件注册表（5 种组件的 type/defaultProps/schema） |
| `web-app/src/pages/card/cardDetail.vue` | 名片详情页「简介」标签下渲染自定义组件区 |
| `web-app/src/pages/card/myCard.vue` | 「名片内容」编辑列表入口：装修我的名片 |
| `server/src/db.js` | 新表 `card_components`（含母版字段） |
| `server/src/routes/card.js` | `GET/PUT /cards/:id/components`（母版注入 + 整存） |
| `web-app/src/utils/cardApi.js` | `getCardComponents` / `saveCardComponents` |

## 1.2 数据模型（card_components）

```sql
CREATE TABLE IF NOT EXISTS card_components (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  card_id INTEGER NOT NULL DEFAULT 0,      -- 个人组件=名片id；母版=0
  customer_id INTEGER,                      -- 租户（母版按它注入到租户内所有名片）
  type TEXT NOT NULL,                       -- 对齐 componentRegistry：image/channel-video/notice/divider/spacer
  props TEXT NOT NULL DEFAULT '{}',        -- JSON，对齐 registry defaultProps/schema
  sort_order INTEGER NOT NULL DEFAULT 0,
  source TEXT NOT NULL DEFAULT 'user',     -- user=归属人自建；master=企业母版（只读注入）
  status TEXT NOT NULL DEFAULT 'active',
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);
```

- `source='master'` 且 `card_id=0`：租户级母版，对租户内所有名片**只读注入**（`isLock:true`），成员不可改——这就是原稿「企业母版锁定」的落地方式，无需额外锁机制。
- `type`/`props` 与 PC 编辑器 `componentRegistry.js` **逐字一致**（单测 `cardCompRegistry.test.js` 钉死 defaultProps 与 schema 键，防两端漂移）。

## 1.3 API（挂 card.js，C 端 card_token 鉴权）

```
GET  /api/card/cards/:id/components        公开读（名片详情页渲染用）
     → { components: [...母版(isLock:true)在前, ...个人组件] }

PUT  /api/card/cards/:id/components        整存（仅名片归属人）
     body: { components: [{ type, props }] }   数组顺序即展示顺序
     服务端强制：type 白名单（5 种）/ 剥离 source·isLock·cardId·customerId（防伪造母版）/ 上限 20
```

## 1.4 交互流程（与原稿一致的部分）

1. 我的名片 → 名片内容 → **装修我的名片** → 进入 cardEdit；
2. 组件列表：母版卡片置灰（🔒 企业母版 + 红色提示），个人卡片可操作；
3. 底部「＋ 添加组件」→ 弹出 5 种组件网格 → 选中后追加到末尾并**直接弹出配置窗**（必填项当场补）；
4. 上移/下移（不能穿越母版）/ 编辑 / 删除 → 每次操作**自动整存**（PUT 全量个人组件）；
5. 配置弹窗按注册表 schema 渲染控件：input / image（选图后走通用上传）/ color（色板+hex）/ slider / radio / switch；
6. 名片详情页「简介」标签下按顺序渲染母版+个人组件。

## 1.5 组件字段速查（与 PC 编辑器对齐）

| type | 名称 | 关键 props | 备注 |
| ---- | ---- | ---- | ---- |
| `image` | 图片 | url / link / radius / 边距 | 点击跳站内路径 |
| `channel-video` | 视频号 | **finderUserName + feedId** / cover / title / desc | 原稿的 `feedToken` 是旧模型，已废弃；点击走 `wx.openChannelsActivity` |
| `notice` | 文本 | text / bgColor / color / fontSize / bold | 原稿「文本」映射到注册表的公告组件 |
| `divider` | 分割线 | text / color / thickness / lineStyle | |
| `spacer` | 空白占位 | height / bgColor | |

## 1.6 与原稿的差异（落地时修正）

1. 技术栈：原生小程序 → uni-app Vue3（`uni.*` API、`pages.json` 注册路由）；
2. 视频号字段：`feedToken` → `finderUserName` + `feedId`（视频号助手获取）；
3. 「文本」组件：原稿虚构的 `text`/`tag` 类型 → 注册表现实的 `notice`（公告）；
4. 母版锁定：原稿的 `isLock` 数据字段 → 服务端按 `source='master'` 注入 `isLock`，前端只读；
5. 权限：原稿「员工可改自己新增的组件、管理员可解锁母版」→ V1 只做「归属人可改个人组件，母版全员只读」；母版管理页（租户管理员增删改）在 V1.1；
6. 保存：原稿 `saveSchema` 占位 → PUT 整存（服务端白名单+防伪造+上限）；
7. 配色/单位：原稿硬编码 `#07c160` 与 rpx → 项目设计令牌（`var(--design-primary)` 等，tokenAudit 单测扫裸值）+ px/vw 约定；
8. Tab 归属：原稿「组件挂到简介/作品/动态/视频四个 Tab」→ V1 统一渲染在「简介」 Tab 下，按 Tab 分组在 V1.2。

## 1.7 迭代规划（更新）

| 版本 | 内容 | 状态 |
| ---- | ---- | ---- |
| V1.0 | 个人组件装修主流程（5 种组件、增删/排序/编辑/整存/渲染、母版只读注入） | ✅ 2026-10-20 已上线 |
| V1.1 | PC 母版组件管理页（租户管理员增删改母版，成员只读） | 待排期 |

# 二、开发文档 / PRD

## 文档名称：零壹系统云-电子名片 手机端简易装修开发文档

### 1. 模块概述

- **页面路径**：`pages/card/cardEdit`（uni-app 路由，见 `web-app/src/pages.json`）
- **入口**：我的名片 → 名片内容 → 装修我的名片（仅名片归属人可见；访客无入口）
- **核心能力**：纵向列表管理组件，无画布自由拖拽；支持新增、排序、编辑、删除自定义组件；企业母版组件只读注入（服务端 `source='master'`）；与 PC 拖拽编辑器共用同一套组件定义（`componentRegistry.js`），两端识别一致。
- **技术方案**：uni-app 页面，组件列表 + 底部弹出面板 + 居中配置弹窗；保存走 `PUT /cards/:id/components` 整存。

### 2. 完整操作流程（P0 核心流程）

1. 进入页面 → 拉取 `GET /cards/:id/components`，渲染母版（置灰）+ 个人组件列表；
2. 点击底部【＋ 添加组件】→ 底部弹出组件选择网格（5 种）；
3. 点击组件卡片 → 追加到个人组件末尾并弹出配置窗；
4. 填写配置（视频号需 finderUserName + feedId）→ 保存 → 自动整存；
5. 点击【上移/下移】调整顺序（不能穿越母版）；【删除】移除个人组件；
6. 名片详情页「简介」标签下实时可见最终效果。

### 3. 数据模型

见 1.2（`card_components` 表）。统一 Schema 示例：

```json
{
  "components": [
    { "type": "channel-video", "props": { "finderUserName": "sPh7vD5...", "feedId": "106511204134634884", "title": "商会宣传片" } },
    { "type": "notice", "props": { "text": "欢迎合作", "bgColor": "#FFF7E8" } }
  ]
}
```

- 母版组件不下发到 PUT payload（前端只读，保存时自动剔除）；
- `type` 严格对齐 PC 端注册表，双端识别一致（单测钉防漂移）。

### 4. 交互规则（动效 + 反馈）

1. 底部弹出面板：从下向上滑入；点击遮罩/取消关闭；
2. 配置弹窗：居中弹出，遮罩半透明；点击外部遮罩关闭；
3. 按钮状态：母版组件所有操作按钮置灰 + 文字提示；
4. 操作反馈：每次变更自动整存，toast「已保存」；
5. 新增规则：新组件追加到个人组件末尾（母版之后），不插入中间。

### 5. 权限边界（V1）

- **名片归属人**：可增删改排序自己的组件；不可见改母版（只读置灰）；
- **企业母版**：租户级只读内容，V1 由平台/运营侧数据写入（`source='master'`），V1.1 做 PC 管理页；
- **访客**：看不到装修页，仅在名片详情页看最终渲染效果。

### 6. 兼容性

- uni-app 双端（H5 + 微信小程序）；小程序基础库 2.30+；
- 样式走项目设计令牌（CSS 变量），颜色/字号/圆角/层级不写裸值（tokenAudit 单测强制）；
- 颜色选择器色板为预设 10 色 + 透明 + 自定义 hex 输入。

# 三、UI 设计师需求清单

> 视觉基调维持原稿；两处按项目纪律修正：主色用**品牌主色**（`var(--design-primary)`，后台「品牌外观」可配），不再写死微信绿 `#07c160`；尺寸/圆角/字号优先复用设计令牌。

## 1. 页面基础信息

- **页面名称**：手机名片简易装修页
- **设备**：iPhone 14（375px 宽度，小程序竖屏）
- **整体风格**：简约商务白底卡片，和名片主页视觉统一；
- **色值**：主色=品牌主色（`--design-primary`）；文字主色 `--t1`；次要 `--t2`；装饰灰 `--decor`；禁用 `--decor-2`；危险色 `--danger`。

## 2. 页面模块尺寸规范

### 2.1 顶部导航栏
- 复用项目 `PageNav` 组件（自定义导航，胶囊避让），无需单独设计。

### 2.2 组件列表卡片
- 白底、圆角 `--radius-md`、内边距 `--space-r5`、卡片间距 `--space-r4`；
- 母版卡片：浅灰底（`--bg-card`）+ 🔒 图标 + 「企业母版」橙色标签（`--brand-orange`）+ 红色提示文字；
- 操作按钮：上移/下移/编辑/删除；删除为危险色描边；最小点击区域 44×44px。

### 2.3 底部悬浮添加按钮
- 通栏胶囊（高度 88rpx，圆角 pill），品牌主色实心 + 白字；不随页面滚动。

## 3. 底部组件选择面板

- 顶部大圆角（`--radius-lg`）白底面板；4 列网格；图标（emoji：🖼️🎬📝➖▭）+ 文字；
- 底部取消按钮通栏，顶部分割线；
- 动画：向上滑入 300ms。

## 4. 配置弹窗（按组件类型动态渲染）

- 宽度 85% 屏幕，圆角 `--radius-lg`，最大高度 76vh，内部滚动；
- 控件：单行输入 / 多行输入 / 图片上传（160×120 预览）/ 色板（10 色 + 透明 + hex）/ 滑块 / 单选 chips / 开关；
- 底部双按钮：取消浅灰底，保存品牌主色底。

## 5. 视觉状态清单

1. 默认常态；
2. 母版锁定态（按钮置灰 + 标签 + 提示）；
3. 按钮点击按压态；
4. 弹窗遮罩：黑色半透明（`--bg-mask`）。

## 6. 交付物要求

1. 组件列表卡片两种状态（个人/母版）效果图；
2. 组件选择面板 + 各组件配置弹窗效果图；
3. 色板与控件规范（对齐令牌）；
4. 交互动效参数（时长、缓动曲线）。
