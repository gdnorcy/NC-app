# 四、关键业务规则（闭环约束）

- **登录静默 \+ 必要授权：**微信静默登录，无需强制授权即可浏览；创建/留资时按需授权。

- **名片校验：**行业、地址未完善则不能对外展示，返回引导（tipPerfect→去完善）。

- **全量留痕：**点赞/收藏/分享/电话/微信/地址导航每个动作都上报雷达（like\_card/collect\_card/share\_card/call\_tel/…）。

- **支付回调幂等：**订单 status==0 判重，按 type 分发（VIP/模板/合伙人/置顶），随后触发分佣 Hook。

- **分佣规则：**直推 proportion1 \+ 间推 proportion2，单笔比例 ≥1 才入账（防零元分佣）。

- **模板状态机：**0 购买 → 1 使用 → 2 已使用；VIP 按等级享受折扣。

- **提现：**受 withdrawal\_limit 限制；自动企业付款失败回滚到余额。

- **雷达闭环：**配置→规则→事件匹配→意向分→话术→推送→打标签，是运营型雷达而非记录型。
