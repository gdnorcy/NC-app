05三套方案

同一份体检数据，三种投入产出比。A 只修错不改观，B 令牌化（推荐），C 体系重建 + 视觉升级。

方案 A · 保守

只修错，不改观感

  • 几何：修 3 个偏小 + 8 个偏心图标
  • 去重：chart/analytics、crown/badge 合并为别名
  • 风格：6 个实心点改描边（或统一 fill 规则）
  • 尺寸：18/20/24/32px → 36/40/48/64rpx（纯单位换算，视觉几乎不变）
  • 颜色：77 处硬编码 → --t1~--t4 / --ink-3（7 种灰收敛为 3 档）
  • 不动：字号、间距、圆角、阴影、z-index
改动 ~120 处零视觉风险

方案 B · 均衡 （推荐）

令牌化 + 光学归一化

  • 含方案 A 全部
  • 图标光学归一化：60 个统一到 80%±3% 视觉占比并居中
  • 字号：68 种 → 8 档（20/22/24/26/28/32/36/44rpx）
  • 圆角：→ 4 档（8/12/16/24rpx + pill）
  • 间距：→ 4pt 栅格（8/12/16/20/24/32rpx）
  • 阴影：46 种 → 3 档（xs/sm/md）+ 统一聚焦环
  • z-index：25 个 → 6 层（base/content/sticky/nav/popup/toast）
  • px → rpx 全量迁移（消除跨端漂移）
  • 色值：155 hex → ~24 个语义令牌
改动 ~900 处需逐页回归

方案 C · 激进

设计系统重建 + 视觉升级

  • 含方案 B 全部
  • 图标库重建：按 24 网格 / 1.75 描边 / 20×20 安全区重绘，或引入 Lucide 子集（体积需评估，MP 主包现 1448KB）
  • 排版层级：显示级 / 标题 / 正文 / 辅助 四级 + 字重阶梯
  • 卡片体系统一：白卡 + 弱描边 + 三档阴影，页底灰统一
  • 动效令牌：统一 transition 曲线与时长，加入按压反馈
  • 纹理与渐变：关键页加入渐变网格 / 噪点，摆脱纯色块
  • 暗色模式预留：令牌全部走 CSS 变量
改动 ~2000+ 处需完整视觉走查

06建议路线

先 A 后 B，C 视品牌阶段另立项。

A 是「零争议」部分 —— 11 个几何异常的图标和 2 组重复，属于明确的错误而非审美分歧，可独立提交、独立回归。

B 解决的是真正的系统性问题：68 种字号、46 种阴影、25 层 z-index、155 种色值 意味着每次改一个视觉参数都要改十几处，且必然漏。令牌化一次投入，后续每次改版成本降一个量级。

C 涉及审美方向选择（卡片质感 / 纹理 / 动效 / 字重），需要你先定调，不建议在规范未收敛时铺开 —— 否则会和 B 的令牌化互相返工。
