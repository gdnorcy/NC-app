视频号作品 ID / 封面提取

给名片挂视频号作品时，免掉手工抄 ID 的步骤
它做什么：在你已经登录的视频号助手页面里，读取当前页面的作品数据， 列出每条作品的 feedId 和封面，点一下就复制。
安全边界：只在你自己的浏览器里读取页面数据并显示出来， 不上传到任何服务器、不改写任何请求、不碰你的账号。 和「res-downloader」那类装根证书做中间人代理的思路完全不同——不需要装证书、不需要配代理。

方式一：油猴脚本（推荐，一次安装长期可用）

  1. 浏览器装 Tampermonkey（油猴）扩展：Chrome / Edge 应用商店搜 "Tampermonkey"
  2. 点扩展图标 → 创建/导入新脚本 → 把 feedid-helper.user.js 内容粘进去并保存
  3. 打开 channels.weixin.qq.com 并登录，页面右侧会出现绿色「提取作品 ID」按钮，点它

方式二：书签小工具（零依赖，任意浏览器）

  1. 点下面按钮复制代码
  2. 在书签栏（Ctrl/⌘ + Shift + B 可显示）右键 → 添加网页/书签
  3. 名称随便起（如「提取作品ID」），网址栏粘贴刚才复制的代码
  4. 登录视频号助手后，点一下这个书签

怎么用

  1. 电脑浏览器打开 https://channels.weixin.qq.com，扫码登录（必须是该视频号的管理员）
  2. 进入内容管理的作品列表，如果数据没自动出来，滚动一下列表或翻页（让列表接口跑一次）
  3. 面板会列出作品：封面缩略图 + 标题 + feedId，点「复制 feedId」
  4. 视频号ID（sph 开头）在助手首页顶部能看到，复制到名片的第一个输入框

如果没抓到

  • 先点面板上的「重新扫描页面」，再滚动列表让它刷一次接口
  • 确认登录的是该视频号的管理员微信（运营者需管理员先授权）
  • 面板底部会显示「已扫描对象数 / 接口次数」——把这两个数字和截图反馈过来， 就能按真实页面结构补上对应提取路径（视频号页面结构会随版本变化，本工具做了三条兜底路径）
注：本工具只是省掉抄 ID 的手工活，不改变数据来源——feedId 与视频号ID 的合规来源仍然是 微信官方的视频号助手。微信未开放「由分享短链反查 feedId」的接口（weixin.qq.com/sph/ 是加密路由短链）， 服务端无法解析，所以这一步必须由用户在自己登录态下完成。
