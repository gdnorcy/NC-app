「我的名片」页配色审计 & 优化效果图

现状问题：一屏混用 5 种互不相干的强调色相（金 / 琥珀 / 绿 / 藏蓝 / 红），远超「一主色 + 中性 + 语义克制」的现代设计底线，显得杂乱、不专业。
优化方向：单一主题色（跟随租户）统领所有交互/身份元素 + 中性色承载工具型操作 + 语义色只用于真实状态。

收敛后的用色

主色（主题红）· 头像/标签/图标/链接/CTA/激活态
中性深灰 · 工具型操作图标（预览/分享/复制）
中性浅灰 · 分割线/次要文字/占位
语义绿 · 仅「已上架/成功」状态
语义琥珀 · 仅「待审核/警告」状态

配色体系（贯穿全站，一次性收敛）

① 单一主色
租户主题 --design-primary 作为唯一强调色，接管所有交互/身份元素：列表图标、文字链接、激活态、CTA、头像兜底、标签底色。
② 中性承载
预览/分享/复制/导出等工具型操作改用中性深灰，不再用绿色；大量留白 + 白卡 + 细分割线 + 柔和阴影，质感靠排版不靠彩色。
③ 语义克制
绿=成功/已上架、琥珀=待审/警告、红=危险/退出 —— 只用于真实状态提示，绝不作装饰色。一屏内语义色 ≤ 1~2 处。
令牌来源：主色=--design-primary / --design-primary-rgb（design.js，随租户主题）；语义与中性沿用 token.scss。
关键动作：把散落全站的平台蓝 #165dff / #1d4e8f（--primary / --primary-deep）从「强调色」位撤下，仅留作无主题时的兜底 —— 这是红/绿等自定义主题下「蓝图标撞红 CTA」的根因。
