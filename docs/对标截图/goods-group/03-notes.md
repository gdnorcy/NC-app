# 商品组（goods-group）ew 对标笔记

## C 端渲染样式（01-render.png）
- 单列卡片，左图右文布局
- 左边：商品图（方形圆角）
- 右边：
  - 红底白字小标签"标题标签" + 商品标题（黑色粗体）
  - 副标题（灰色小字）
  - 价格：¥20（红色）/件（灰色）
  - 右边：红色圆角"购买"按钮（购物车样式）
- 卡片白色背景，圆角，左右有间距

## 配置面板字段（02-props.png）
- 样式：选择风格（多种布局风格可选）
- 选择商品：数据来源（全部/分类/手动指定）
- 颜色设置：
  - 底部背景
  - 商品背景
  - 购物车按钮：文字/颜色/圆角/背景/边框/尺寸
  - 点击购物车按钮（跳转设置）

## 与我现有实现的差异
- 我做的：双列网格商品卡片（图片在上，标题价格在下）
- ew 实际：单列左图右文 + 购买按钮
- 配置字段：我做的只有 title/source/catId/goodsIds/limit/showPrice/showSales/bgColor/radius/marginTop/marginBottom/memberLevel
- ew 实际：选择风格/选择商品/颜色设置（底部背景/商品背景/购物车按钮样式）
