# 全部商品组件交互确认（2026-09-20）

## 控件表现方式（从ew HTML读取）
- 样式：radio-button（按钮组样式）
- 选择风格：radio-button goods（带缩略图按钮组）
- 选择商品：普通radio（圆圈，一行不换行）
- 排序方式：普通radio
- 颜色设置：common-color（圆形色块）
- 显示内容：checkbox列表（竖排）
- 购物车按钮：普通radio（显示/隐藏）+ 展开后样式/文字/颜色/圆角/背景/边框/尺寸/点击动作
- 角标设置：普通radio
- 边距/圆角：common-slider（label+slider+px）
- 会员权限：普通radio

## 风格间差异
| 参数 | st1/st2（单列） | st3（双列网格） |
|------|---------------|---------------|
| 卡片轮播 | 无 | 有（关闭/开启） |
| 副标题 | 有（switchColor） | 无 |
| 图片比例 | 无 | 有（1:1/3:4/4:3/16:9） |
| 尺寸 | 有（小/中/大） | 无 |

## 默认值
- 样式：默认；风格：st1；商品来源：全部商品；排序：按权重
- 购物车按钮：显示；角标：不显示；边距：商品间距7/上下12/左右12；圆角：4
