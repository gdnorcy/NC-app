## 零、面板结构总览

组件选中后右侧面板 = **2 个 tab**：

| tab | class | 说明 |
|---|---|---|
| 内容设置 | `.setting-tabs__item` [0] | 组件属性 + 组件内容 |
| 样式设置 | `.setting-tabs__item` [1] | 组件背景/整体/风格/颜色 |

面板顶部还有一组**组件级布局切换**（区别于顶栏的表单级）：
`.top-header-styles.mt-20` → 子项 `上下布局` / `左右布局`，默认 `上下布局`。

## 一、内容设置 tab

### 1.1 组件属性（4 个字段，全是纯开关，**均无后续联动**）

| 字段 | 控件类型 | 选项 | 联动 |
|---|---|---|---|
| 是否显示： | `setting-radio`（radio-button） | 显示 / 隐藏 | 无面板联动（画布隐藏组件） |
| 是否必填： | `setting-radio` | 必填 / 非必填 | 无 |
| 只读： | `el-switch` | — | **无新增字段**。副文案：`开启只读则必填"预填文字"，用户无法修改` |
| 内容校验： | `el-switch` | — | **无新增字段**。副文案：`开启校验则相同内容无法重复提交` |

> 踩坑记录：只读 / 内容校验实测各点一次，面板 innerText 完全不变 —— 这两个开关在
> 单项选择组件上**只写值、不派生 UI**，不要照着文案去造"预填文字"输入框。

### 1.2 组件内容

| 字段 | 控件 | 说明 |
|---|---|---|
| 内容标题： | `input[text]` | 画布 label 文字 |
| 选项类型： | `setting-radio` | 文字选项 / 图片选项 / 图文选项 |
| 添加选项： | 自定义 `radio-list__item` 列表 | 见下 |

### 1.3 添加选项区（**本次最关键的发现**）

每一行 `.radio-list__item` 的结构固定为：

```
[i.icon-drag_2 拖拽手柄] + [setting-input-radiolist 输入框 / setting-radio-btn 图片按钮] + [删除]
```

- 输入框带 **prefix 标签「选项」**（`el-input__prefix`），文案为空时显示灰色 placeholder「选项」
- 拖拽手柄 `icon-drag_2` → **选项可拖拽排序**（我方当前无此能力）

底部操作区三个入口：

| 入口 | 行为 | 实测结果 |
|---|---|---|
| 新增选项 | 直接追加一行空选项 | 新行 prefix 仍为「选项」，值可编辑，**有删除按钮** |
| 添加其他选项 | **不是弹窗**，直接追加一行 value=`其他` 的普通选项 | 同样是可编辑 input + 删除，**没有"其他"专属的填空输入框** |
| 批量添加 | 弹窗「批量添加选项」 | textarea（placeholder=`请输入选项内容`），提示`每个选项请单列一行，单个选项长度不能超过100个字`，按钮`取消 / 确定`；确定后按换行 split 追加为多行选项，**画布实时出现「苹果/香蕉/西瓜」** |

按钮区用 `.el-divider--vertical` 竖线分隔，且**「添加其他选项」「批量添加」仅在「文字选项」时出现**。

### 1.4 选项类型三档的真实联动（★ 上一轮复刻失败点）

| 选项类型 | 面板「添加选项」行结构 | 底部按钮 | 画布渲染 | 样式设置字段 |
|---|---|---|---|---|
| 文字选项 | 拖拽 + prefix「选项」+ 文字 input + 删除 | 新增/其他/批量 | 圆点 + 文字 | 全量（8 个颜色） |
| 图片选项 | 拖拽 + `setting-radio-label`「选项」+ **`setting-radio-btn`「选择图片」** + 删除 | **只剩「新增选项」** | 灰色占位块 + 序号 | **精简**：只保留 标题颜色/错误提示 |
| 图文选项 | 图片按钮 + 文字 input | — | 图片 + 文字 | — |

**两个关键副作用（我方必须复刻）：**
1. 切换选项类型时，**选项列表被重置**（实测从 3 行 → 1 行），不是保留原选项。
2. 切到「图片选项」后样式设置里**「组件风格」三档选择器整块消失**，
   `底框边框 / 底框背景 / 提示文本 / 选项文本 / 其他线条` 5 个颜色全部隐藏。
   → 即：**图片选项下风格切换是失效的**（对标站自身行为，照抄即可，不要自己"修好"）。

## 二、样式设置 tab（5 个分区）

分区条实测（`.setting-header-block`）：

```
组件背景   背景类型：(颜色 / 图片+颜色)  背景颜色 #FFFFFF
组件整体   顶外边距 / 上下边距 / 左右边距 / 组件圆角
组件风格   [风格1|风格2|风格3 图形卡片]  左右边距 / 输入框圆角 / 标题大小
组件颜色   标题颜色 #000000 / 底框边框 #F5F2F2 / 底框背景 #F7F9FA /
           提示文本 #999999 / 错误提示 #ED4F4F / 选项文本 #333333 / 其他线条 #F5F2F2
```

- 「组件风格」选择器 class = `.style-editor` > `.style-editor__item` > `.style-items`（含 base64 PNG 缩略图）
  - 缩略图已下载存档：`ew-radio-style-1-缩略图.png` / `-2-` / `-3-`
  - 点击 `.style-items` 才会触发 Vue 绑定；点内部 `input` **无效**（实测 class 不变）
- 三档风格**面板字段完全相同**（文字选项下），差异全在 class 名的 CSS 规则

### 2.1 三档风格的画布 class 映射

| 风格 | item class | radiogroup class |
|---|---|---|
| 风格1 | `box1-radio` | `top-box1-radio` |
| 风格2 | `box2-radio` | `top-box2-radio` |
| 风格3 | `box3-radio` | `top-box3-radio` |

> 三档的 **inline CSS 变量完全相同**（`--border-color:#F5F2F2; --bg-color:#F7F9FA;
> --radio-color:#333333; --active-color:#2667EC; --align-items:left;` 等），
> 视觉差异 100% 来自 CSS 规则，不来自变量。

### 2.2 三档风格的真实 CSS 语义（从 CSSOM 提取原文）

**风格1 `top-box1-radio`（卡片式）**
```css
.top-box1-radio { width: 100%; }
.top-box1-radio .el-radio { display: block; width: 100%; margin-bottom: 5px; }
.top-box1-radio .el-radio .el-radio__label {
  min-height: 41px; display: inline-block; width: calc(100% - 36px);
  background: var(--background-color); margin-left: 10px;
  color: var(--radio-color); border: 1px solid var(--border-color);
  border-radius: var(--border-top-left-radius) var(--border-top-right-radius)
                 var(--border-bottom-left-radius) var(--border-bottom-right-radius);
  word-break: break-all; white-space: normal;
}
```

**风格2 `top-box2-radio`（纯文字）**
```css
.top-box2-radio .el-radio.is-checked .el-radio__label { color: var(--radio-color); }
.top-box2-radio .el-checkbox { margin-right: 14px; }
.top-box2-radio .el-checkbox__label { color: var(--radio-color); word-break: break-all; }
/* 关键：选中态文字不变色（仍是 --radio-color），无底框无背景 */
```

**风格3 `top-box3-radio`（胶囊 + 蓝底白字）**
```css
.top-box3-radio .el-radio.is-checked .el-radio__label {
  background: var(--active-color);   /* ★ 唯一使用 active-color 的档 */
  border-color: var(--active-color);
  color: rgb(255, 255, 255);
}
.top-box3-radio .el-checkbox__input { display: none; }  /* 隐藏勾选框 */
.top-box3-radio .el-checkbox__label {
  padding: 9px 15px; background: var(--background-color);
  border: 1px solid var(--border-color); border-radius: <四角>;
  font-size: 13px; color: var(--radio-color);
}
```

**★ 核心结论：我方 `sfx-optbox/sfx-optplain/sfx-optline` 的语义划分与对标站一致，
但缺了「选中态填色」这一档 —— 风格3 选中时是 `--active-color` 蓝底白字，
我方三档目前选中态都没有填充表现。**

### 2.3 上下布局 / 左右布局

| 布局 | wrapper class | label | 差异 |
|---|---|---|---|
| 上下布局 | `field-wrapper-radio-top` | `field-wrapper-label-top`，`label width:0` | 标题独占一行，选项整块在下方 |
| 左右布局 | `field-wrapper-radio-left` | `field-wrapper-label-left`，`label width:90px; content margin-left:90px` | 标题与选项同行，标题固定 90px |

左右布局补充规则：
```css
.left-radio-alignment { width: 100%; }
.left-radio-alignment .el-radio { display: block; width: 100%; text-align: var(--align-items); }
.left-radio-box1.left-radio-wrap { padding-left: 10px; }
.field-wrapper-label-left.radio-alignment .el-form-item__label { top: 18px; }  /* 垂直居中 */
```

- **`--align-items`** 变量控制选项文字对齐（`left`/`center`），默认 `left`
- 切换布局时**面板字段完全不变**

## 五、抓取方法论沉淀（踩坑）

1. **点 `input` 无效，必须点 `.el-radio` / `.style-items` / `.top-header-styles__item`**
   —— Vue 事件绑在外层 label/div 上。
2. **弹窗要按可见性筛**：`.el-dialog__wrapper` 中 `offsetHeight>0` 的那个；
   `button` 在 wrapper 内，不在 `.el-dialog__body` 内。
3. **panel-container 切换后旧 DOM 引用失效** —— 每次操作后重新 query。
4. **批量添加确定后，画布已更新但面板 innerText 不变** —— 以画布为准判断是否生效。
5. **读 CSSOM 优于看截图**：`document.styleSheets` 遍历 `cssRules`，
   按 `selectorText` 过滤，能拿到三档风格的精确视觉语义。
6. **base64 缩略图不能靠 eval 回传**（输出被截断）——
   在页面内 `a.download` 触发下载，再从 `~/Downloads` 取。
7. 组件级 vs 表单级 `.top-header-styles` 同名，
   用 `closest('.setting-panel-right')` 区分。
