## 一、后台结构

### 表单列表页（01-render-列表页.png）
- 两个 tab：**表单列表** / **信息列表**（收集到的数据）
- 按钮：搜索、**添加表单**
- 表格列：表单名称 / 表单收集时间 / 创建时间

### 拖拽设计器（02-editor-*.png）三栏布局
- 顶栏：基础布局（上下布局/左右布局/样式设置）｜表单设置｜保存页面｜保存并发布
- 左栏：组件库（点选即添加，也可拖拽）
- 中栏：手机预览画布（组件选中后出现 上移/下移/复制/删除 浮层）
- 右栏：配置面板（未选中组件=表单设置；选中组件=组件配置）

## 三、组件配置面板模式（03/04/07/08-*.png）

每个组件配置 = **内容设置 / 样式设置** 两个 tab：

### 内容设置
- 组件属性：是否显示（显示/隐藏）、是否必填（必填/非必填）
- 组件内容（随组件类型变化），以单行文本为例（03-props-单行文本*.png）：
  - 内容标题*、提示文字、预填文字
  - 内容类型：普通 / 手机号码 / 邮箱 / 身份证 / 扫码识别（暂不支持H5端）
  - 同步姓名：开启/关闭
  - 输入类型：中文/英文/数字/符号
  - 输入限制：最少输入 0 位、最多输入 400 位（slider+stepper）
- 只读、内容校验（相同内容无法重复提交）开关

### 样式设置（04-props-单行文本-样式.png）
- 组件风格：框风格 / 线风格
- 左右边距、输入框圆角、标题大小、输入文本大小（slider+stepper）

## 四、表单设置（05/10-*.png，右栏全局）

### 基础设置 tab（2026-09-30 二次实测对标站修正）
- 基础信息：表单名称*、收集时间（开始/结束日期，*注：嵌入式表单不生效）、收集份数（stepper 0 起，"0 为不限制（*注：嵌入式表单不生效）"）、允许修改（开关）
- 填写设置（16/17/18-*.png，*注：该模块嵌入式表单不生效）：
  - 填表人群：⦿全部（包含游客） / ○授权用户 / ○指定等级 / ○密码
    - 指定等级 → 出现「请选择等级（可多选）」下拉（数据来自会员等级体系）
    - 密码 → 出现输入框「密码最多20位」
  - 提交周期：按钮组 永久 / 每天 / 每周 / 每月 / 每年（默认永久，无日期范围联动）
  - 次数：stepper + 次；注释随人群变化：全部→"0为不限制（游客填写时不受次数限制）"，其他→"0 为不限制"
  - 注：次数=按填写人计数（游客不限），与基础信息的收集份数（按总数）是两个独立限制
- 分享：分享标题、分享图片
- 提交设置（*注：该模块嵌入式表单不生效）：二次确认（开关）、跳转页面（请选择链接或输入链接地址 + 选择链接按钮，不选则停留当前页面不进行跳转）

### 逻辑设置 tab（05/06-*.png 初稿 → 19/20-*.png 2026-09-30 实测+读 ew 运行时源码确认）
- 说明文案（原文）："提示：请添加完所有组件之后再设置该逻辑部分（分页以及提交按钮不参与逻辑部分设置）。你可以为选择类字段（单项选择、多项选择、评分、下拉选择）设定规则，填写者选择某字段的某选项后，显示该字段之后的其他字段。操作文档：点击跳转"
- 字段白名单（读源码 conditions）：`radio / checkbox / rate / select`，与文案一致
- 规则结构：规则N（可折叠）=「当满足以下条件时」→ 条件行「在 [字段] [选项] 删除」+「添加条件」→ ⦿则显示字段 / ○则结束表单 → 显示：[多选，候选=触发字段之后的字段]
- 条件语义（读源码 changeWidgetelect）：
  - radio/checkbox → 比较符「选择了任一」（select_any），选项**多选**
  - select → 比较符「选择了」（equal），选项单选
  - rate → 比较符「介于」（between），两个下拉 最低~最高（1..最高量级）
- 多条件：条件行间出现「或/且」选择（rule.operator，默认 or；首行 el-select、其余行显示文本）
- 确定按钮校验（读源码 submitFieldRules）：
  - 重复条件 → "逻辑条件设置中存在相同项，请修改后再保存！"
  - 有「则结束表单」但表单无提交按钮 → "请确保DIY表单中存在提交按钮！"
- 底部按钮：+ 添加规则 / 确定 + "请点击确认按钮完成逻辑设置部分"
- 附：ew 的逻辑字段列表在**设计器加载时**快照（filterSelector 只在载入时调用），我们按画布实时计算（更优）

### 全局样式 → 页面背景（12/13/14/15-*.png，2026-09-30 实测）
- 背景类型：⦿颜色 / ○图片+颜色
- 颜色：仅 背景颜色（#f3f3f3 + 重置）
- 图片+颜色 → 背景图片（图片地址 + 选择图片）、平铺方式（左右重复/上下平铺/都平铺/不平铺）、左右位置（左/中/右）、上下位置（上/中/下）、图片样式（自定义/填充/图片固定比例）、背景图宽/背景图高（slider+stepper，%，仅"自定义"时显示；填充与固定比例都隐藏宽高）、背景颜色 + 重置
- ew 内部键名（formConfig）：bgStyle / backgroundColor(#f3f3f3) / backgroundImg / repeat(repeat-x 默认) / positionx(left) / positiony(top) / backgroundImgSizeType(0=自定义,1=填充,2=固定比例) / backgroundImgSizeWidth(20) / backgroundImgSizeHeight(20)

### 评分组件（21/24/25/26-*.png，2026-09-30 实测）
- 组件属性：是否显示（显示/隐藏）、是否必填（必填/非必填）
- 组件内容：内容标题*（评分）、描述文字、允许半选（开关，默认关）、最高量级（下拉，默认3）
- **样式设置（24/25/26-*.png，评分专用，非通用框/线）**：
  - 组件背景：背景类型（颜色/图片+颜色）+ 背景颜色（默认 #FFFFFF + 重置；图片+颜色展开完整平铺/位置/图片样式/宽高参数）
  - 组件整体：顶外边距(0) / 上下边距(10) / 左右边距(0) / 组件圆角(0，ew 为四角独立圆角选择器)
  - 组件风格：图标图形单选（表情😊 / 爱心💛 / 星星★，默认表情 icon-xiaolian）+ 左右边距(10) + 标题大小(16)
  - 组件颜色：标题颜色 #000000 / 错误提示 #ED4F4F / 描述文字 #999999 / 未激活颜色 #C6D1DE / 选中颜色 #F7BA2A
- ew 内部键名（rate options）：highestMagnitude / allowHalf / iconClasses('icon-xiaolian') / outMarginTop / innerTopBottomPadding(10) / outLeftRightMargin / componentFillet / labelSize(16) / inputLeftRightMargin(10) / labelColor / describeColor / errorColor / inactiveIconColor(#C6D1DE) / activeIconColor(#F7BA2A) / bgStyle / backgroundColor(#FFFFFF)
- 预览为表情脸；我们用字符字形 ☺/♥/★ 近似，最高量级一致
