# 菜鸟云「超级表单」对标笔记（2026-09-30 抓取）

> 来源：cloud.xincainiao.cc 项目「秘联」→ 应用 → 高级功能 → 超级表单
> 编辑器 URL：`https://cloud.xincainiao.cc/diyform_new/index.html?uniacid=19`
> 后台列表 URL：`/index/vendor._diy_form_controller/lists?appletid=19`

## 一、后台结构

### 表单列表页（01-render-列表页.png）
- 两个 tab：**表单列表** / **信息列表**（收集到的数据）
- 按钮：搜索、**添加表单**
- 表格列：表单名称 / 表单收集时间 / 创建时间

### 拖拽设计器（02-editor-*.png）三栏布局
- 顶栏：基础布局（上下布局/左右布局/样式设置）｜表单设置｜保存页面｜保存并发布
- 左栏：组件库（点选即添加，也可拖拽）
- 中栏：手机预览画布（组件选中后出现 上移/下移/复制/删除 浮层）
- 右栏：配置面板（未选中组件=表单设置；选中组件=组件配置）

## 三、组件配置面板模式（03/04/07/08-*.png）

每个组件配置 = **内容设置 / 样式设置** 两个 tab：

### 内容设置
- 组件属性：是否显示（显示/隐藏）、是否必填（必填/非必填）
- 组件内容（随组件类型变化），以单行文本为例（03-props-单行文本*.png）：
  - 内容标题*、提示文字、预填文字
  - 内容类型：普通 / 手机号码 / 邮箱 / 身份证 / 扫码识别（暂不支持H5端）
  - 同步姓名：开启/关闭
  - 输入类型：中文/英文/数字/符号
  - 输入限制：最少输入 0 位、最多输入 400 位（slider+stepper）
- 只读、内容校验（相同内容无法重复提交）开关

### 样式设置（04-props-单行文本-样式.png）
- 组件风格：框风格 / 线风格
- 左右边距、输入框圆角、标题大小、输入文本大小（slider+stepper）

## 四、表单设置（05/10-*.png，右栏全局）

### 基础设置 tab
- 基础信息：表单名称*、收集时间（开始/结束日期，嵌入式表单不生效）、收集份数（0 不限制）、允许修改（开关）
- 填写设置（10-*.png）：次数限制（0 不限，游客不受限）、分享标题、分享图片
- 提交设置：二次确认（开关）、跳转页面（选择链接，不选则停留）

### 逻辑设置 tab（05/06-*.png，= when 联动）
- 说明：可为选择类字段（单选/多选/评分/下拉）设规则；填写者选了某选项 → 显示其后其他字段
- 规则结构：规则N = 「当满足以下条件时：在 [字段] [选项]（可添加条件）」→ ⦿则显示字段 / ○则结束表单
- 分页和提交按钮不参与逻辑设置

## 五、全局样式设置（09-*.png，顶栏）
- 基础布局：上下布局 / 左右布局
- 距离属性：顶外边距、上下边距、左右边距、组件圆角、左右边距、输入框圆角

## 六、特殊组件要点
- **提交按钮**（07）：内容标题（确认）、提示文字（提交成功后显示）、轻提示开关；在商品下单/报名/会员/文章/视频/音频表单场景不生效
- **表单支付**（08）：规格类型（单规格/多规格）、支付规格表格（规格/价格/库存）、规格单位
- **分页**：表单分页
