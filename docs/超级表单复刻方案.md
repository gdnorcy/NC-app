## 1. 总体架构

### 数据模型（server/src/db.js 新增）
```
super_form        表单定义
  id, applet_id, name,
  pages   TEXT(JSON)   组件树（数组，顺序即渲染顺序；分页=分页组件节点）
  props   TEXT(JSON)   每组件完整配置 {compId: {type, content, style, ...}}
  settings TEXT(JSON)  表单设置：基础信息/填写设置/提交设置/逻辑规则/全局样式
  status, create_time, update_time

super_form_data   提交数据
  id, form_id, user_id(0=游客),
  values  TEXT(JSON)   {compId: value}
  pay_status, create_time
```
- 设计器保存 = 序列化组件树 + 配置；C 端渲染 = 按 type 分发。
- 逻辑规则存在 settings.logic：`[{when:[{compId, option}], action:'show'|'end'}]`。

### 服务端（server/）
- 新增 `superform.js` 服务 + 路由：表单 CRUD / 发布 / C端拉取表单定义 / 提交数据（含游客）/ 信息列表分页查询 / 删除。
- 组织方式对齐现有 FormCollect 的写法。

### 后台（web-admin/src/views/customer/apps/superform/）
- `SuperFormList.vue`：表单列表 + 信息列表 两个 tab（对标 01-render-列表页.png）。
- `SuperFormDesigner.vue`：三栏设计器（对标 02-editor-*.png）：
  - 顶栏：基础布局（上下/左右）、样式设置（全局样式弹层）、表单设置、保存页面、保存并发布
  - 左栏：基础/特殊/装修三类组件库，点选添加 + 拖拽插入指定位置
  - 中栏：手机预览画布，选中态 + 上移/下移/复制/删除
  - 右栏：未选中 → 表单设置（基础设置/逻辑设置 两 tab）；选中组件 → 内容设置/样式设置 两 tab

### C 端（web-app，uni-app）
- 新增独立填写页 `pages/super-form/fill?formId=x`：
  - 渲染器按组件 type 分发；支持上下/左右布局与全局样式
  - 逻辑联动执行：选择类字段选项变化 → 重算各字段显隐；命中「结束表单」→ 截止提示
  - 校验：必填 / 内容类型（手机号/邮箱/身份证）/ 输入限制 / 内容校验（相同内容不可重复提交）
  - 提交链路：收集时间/收集份数/次数限制校验 → 二次确认 → 提交 → 提示文字/跳转页面
- 嵌入模式：同一渲染器可被商品/文章/红包封面以组件形式内嵌（传 formId + embedded 标记，隐藏页面级壳）。
