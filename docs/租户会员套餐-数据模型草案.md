## 1. `benefit_catalog` —— 平台权益目录（schema 归属平台）

把散落在 `member_package` 列、`benefits.js` 常量、`member_levels.benefits` JSON 三处的权益维度，收敛为一张平台统一定义的目录。租户只能配已有 `type` 的值，不能自建 type。

```sql
CREATE TABLE IF NOT EXISTS benefit_catalog (
  type          TEXT PRIMARY KEY,   -- 权益标识，全局唯一
  app_scope     TEXT NOT NULL,      -- 归属应用 code（solutions.code）；多应用用逗号分隔
  kind          TEXT NOT NULL,      -- number | switch | text
  unit          TEXT,               -- 张 / 条 / 折率 / % / 天
  default_value TEXT NOT NULL,      -- 新套餐/新应用时的默认值（存为字符串，按 kind 解析）
  label         TEXT NOT NULL,      -- 后台展示名
  sort_order    INTEGER NOT NULL DEFAULT 0
);
```

## 2. `member_level_app_benefits` —— 套餐 × 应用 权益矩阵

取代当前无人消费的 `member_levels.benefits` 单一 JSON。每个套餐在每个已开通应用上一份权益配置。

```sql
CREATE TABLE IF NOT EXISTS member_level_app_benefits (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  tenant_id   INTEGER NOT NULL,
  level_id    INTEGER NOT NULL,   -- 对应 member_levels.id（即"套餐 A/B/C"）
  app_code    TEXT NOT NULL,
  benefits    TEXT NOT NULL DEFAULT '{}',  -- JSON：{ type: value, ... }，仅存该应用 scope 内的 type
  created_at  TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at  TEXT NOT NULL DEFAULT (datetime('now')),
  UNIQUE(tenant_id, level_id, app_code)
);
CREATE INDEX IF NOT EXISTS idx_mlab_tenant ON member_level_app_benefits(tenant_id, level_id);
```

读取：`SELECT benefits FROM member_level_app_benefits WHERE tenant_id=? AND level_id=? AND app_code=?`。

## 3. `member_package` 降级为"新租户种子模板"

不再作为平台级独立 VIP，而是**新租户初始化时的默认套餐模板**。

- 保留 `member_package` 表不动（其列即目录种子的"参考值"）。
- 新租户创建（`projects` 落库）或首次进入会员模块时，执行种子：
  - 把 `member_package` 的 free/silver/gold/diamond 四档，写入该租户的 `member_levels`（名称沿用、权益按 catalog 默认值 + 各档参考值填 `member_level_app_benefits`）。
  - 用 `schema_marks` 留痕（如 `tenant_seed_pkg_<customerId>`），避免重复播种、且管理员后续改动不被重置。
- 平台 `benefits.js`/`quota.js` 不再读 `platform_user.member_level`，改为消费 `resolveAppBenefits`（见第 4、5 节）。
- 平台保留**不可配硬上限常量**（如 `HARD_CAP_WORKS = 500`、`HARD_CAP_LEAD = 1000`）作绝对天花板，与租户套餐权益分层。

## 4. `resolveAppBenefits` 解析器（伪代码）

```js
// services/member.js
function resolveAppBenefits(tenantId, userId, appCode) {
  const mu = db.prepare(
    `SELECT level_id, status, expire_at FROM member_user WHERE tenant_id=? AND user_id=?`
  ).get(tenantId, userId);
  if (!mu || mu.status !== 'active') return defaultBenefits(appCode);   // 非会员 → 目录默认值
  if (mu.expire_at && expired(mu.expire_at)) return defaultBenefits(appCode);

  const row = db.prepare(
    `SELECT benefits FROM member_level_app_benefits WHERE tenant_id=? AND level_id=? AND app_code=?`
  ).get(tenantId, mu.level_id, appCode);
  const pkg = row ? JSON.parse(row.benefits) : {};
  return { ...defaultBenefits(appCode), ...pkg };   // 目录默认 ⊕ 套餐在该应用的覆盖
}

function defaultBenefits(appCode) {
  const rows = db.prepare(`SELECT type, default_value, kind FROM benefit_catalog WHERE app_scope LIKE ?`).all(`%${appCode}%`);
  const out = {};
  for (const r of rows) out[r.type] = cast(r.default_value, r.kind);
  return out;
}
```

各应用只消费自己 `app_scope` 的 type：商城读 `discount`、集市读 `market_subject`、雷达读 `lead_quota`/`push_quota`、名片读 `works_limit`/`videos_limit`/`voice_enabled`。

## 5. 消费引擎改造点

| 现状 | 改造后 |
|---|---|
| `services/benefits.js` `levelOf` 读 `platform_user.member_level`（平台账号级） | 改为 `resolveAppBenefits(tenantId, userId, 'card')`；`canAddWork`/`canAddVideo`/`canCustomWorksLabel` 基于返回 |
| `services/quota.js` 读 `member_package` 列（collect/lead/push） | 改为消费 `resolveAppBenefits(tenantId, userId, <对应 app>)` 的 collect_limit/lead_quota/push_quota |
| `member_levels.benefits` JSON 无人消费 | 废弃，迁移进 `member_level_app_benefits`（P1f） |

> 平台硬上限常量独立于租户权益：消费方在计算时取 `min(租户套餐权益, 硬上限)`。

## 6. 存量迁移（P1f，草案）

1. **目录种子**：`benefit_catalog` 首次播种（schema_marks `benefit_catalog_seed_v1`）。
2. **新租户种子**：每个租户首次进会员模块，按 `member_package` 四档生成默认 `member_levels` + `member_level_app_benefits`。
3. **存量平台 VIP 用户**：现有 `platform_user.member_level`（free/silver/gold/diamond）作为"该用户所属租户默认套餐"的**初始化参考**——落到对应租户的默认套餐；平台不再单独维护 VIP。
4. **旧 `member_levels.benefits` JSON**：遍历存量行，按 catalog type 拆入 `member_level_app_benefits`（按各 type 的 `app_scope` 分到对应 app_code）。
5. **`member_package` 列**：保留为种子参考值，不再被消费引擎直读。
