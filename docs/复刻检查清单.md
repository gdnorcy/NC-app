# 复刻检查清单（开工前必打勾，缺一项不许动笔）

> **触发条件**：任何"复刻/对标/参考 ew/云菜鸟/nshop 某组件、页面、功能"的任务，开工第一步就是打开本文件逐条打勾。
> **没有截图 = 没开始**。不许先写代码再补截图。
> 截图存 `docs/对标截图/<组件名>/`。

---

## 一、对标站精读（必须先做完这一步，否则不许写代码）

- [ ] **组件渲染截图（C端/设计器画布）**：加进页面后真实渲染，含空态+有数据态，存 `01-render.png`
- [ ] **配置面板全量截图**：选中组件后右侧面板**从上到下滚动截全**（不要只截上半部分），存 `02-props-1.png`、`02-props-2.png`……
- [ ] **所有选项卡/子页面都点一遍**：如有"修改风格""高级"按钮、tab切换、展开收起，逐个点开截图
- [ ] **素材URL抓取**：
  - [ ] 图标/缩略图：用 `bu.js` 读 `document.querySelector('xxx img').src` 或 `backgroundImage`，**下载原版PNG到本地**，记录文件名
  - [ ] **所有带预览图的radio都要抓图**：不只是"风格选择"，购物车按钮样式、角标样式、任何"radio选项带小图标预览"的，都用 `graphic:true` + `img` 字段
  - [ ] 禁止凭语义自创SVG、禁止从本地图标库挑近似图
- [ ] **数量核实（不靠眼睛猜，数DOM）**：
  - [ ] 风格/选项有几个？用 `bu.js("document.querySelectorAll('xxx label').length")` 数
  - [ ] 字段有几个？滚动到底，数 `form-item` 数量
- [ ] **字段联动清单**：
  - [ ] 哪些字段有 when 联动（开A显B），逐条记在 `03-notes.md`
  - [ ] **联动要测**：在对标站点每个开关，观察哪个字段出现/消失，记录完整 when 条件（如"配色=自定义才显示背景色"）
  - [ ] 默认值、选项值逐条记录
- [ ] **两套渲染都要看**：C端实际渲染 + 设计器画布预览，都截图

## 二、写代码时（逐条对照，不许凭名字猜）

- [ ] **schema 字段一个不漏**：对照 `02-props-*.png`，每行字段都有，顺序一致
- [ ] **控件类型对齐系统已有组件**（不许自己发明）：
  - [ ] 可视化风格选择 → `control:'radio', graphic:true`
  - [ ] **任何带小图标的选项**（按钮样式/角标样式/布局样式）→ 也是 `graphic:true` + `img`，不是纯文字radio
  - [ ] 文字选项 → `control:'radio'`（不加 graphic）
  - [ ] 多项内容开关（如"显示内容"9项）→ ew是checkbox多选+每项颜色，先看系统是否有多选控件；没有时才拆成switch+color
  - [ ] 图片上传 → `control:'image'`
  - [ ] 开关 → `control:'switch'`
  - [ ] 滑杆 → `control:'slider'`
  - [ ] 取色 → `control:'color'`
  - [ ] 文本 → `control:'input'`
- [ ] **分组标题正确**：
  - [ ] section 用 `content`/`style`/`member`，对应标签见 PageEditor.vue SEC_LABELS
  - [ ] 需要独立小标题用 `group:'标题文字'`，不要把分组标题留成"内容"
- [ ] **图标用原版PNG**：registry icon 指向下载的图片文件，不自创黑色SVG
- [ ] **缩略图用ew原图**：graphic radio 的 option 加 `img` 字段引用下载的PNG，不用手绘线框图
- [ ] **两套渲染同步改**：C端 `DesignPage.vue` + 设计器 `ComponentRender.vue`，只改一套会出现"C端对了设计器空"
- [ ] **catch 不静默吞错**：数据加载失败必须可见，不能 UI 变空态
- [ ] **不擅自降级**：对标有但本地数据缺的字段，保留字段+默认值，向用户标注"待接入"，不许删掉或换成占位

## 反模式（出现任何一条立即停下，回炉重做）

- ❌ 凭组件名字猜布局，没点开对标站看实际渲染
- ❌ 抓素材失败一次就降级用本地SVG/占位图/手绘线框图
- ❌ 截图只截上半部分，下半部分字段漏了
- ❌ 风格数/选项数靠眼睛估，没数DOM
- ❌ 交付前没并排截图对照，只看"能不能显示"
- ❌ 自创控件类型（如把graphic radio写成普通radio、把图片选择写成input）
- ❌ 把带预览图的选项（按钮样式/角标）写成纯文字radio
- ❌ 没测字段联动就写when条件（如配色=默认时背景色应该隐藏）
- ❌ 分组标题留成"内容"或乱改
- ❌ 只改C端没改设计器预览，或反过来
- ❌ catch 静默吞错导致UI变空态
- ❌ 对标有但本地缺数据就删掉字段
