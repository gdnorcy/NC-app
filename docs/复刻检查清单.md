# 复刻检查清单（开工前必打勾）

> 复刻任何新组件 / 新页面 / 新功能前，**必须**逐条打勾后才允许写代码。
> 截图存到 `docs/对标截图/<组件名>/` 目录。
> 没有截图 = 没开始，不许动 componentRegistry / DesignPage / 任何业务代码。

## 开工前（缺一项就不许动笔）

- [ ] **对标站 C 端渲染截图**：该组件加进页面后，真实渲染样式截图（含空态、有数据态），存 `对标截图/<名>/01-render.png`
- [ ] **对标站配置面板截图**：选中组件后右侧所有配置字段（content/style/交互/高级），滚动截全，存 `02-props.png`
- [ ] **对标站图标/缩略图素材**：`background-image`/`img.src` 抓 URL，下载原版 PNG 到本地 assets，记录文件名
- [ ] **字段联动清单**：配置面板里哪些字段有 `when` 联动（开A显B）、哪些开关、默认值，逐条列在 `03-notes.md`
- [ ] **截图齐全**：上面 3 张截图 + 1 份笔记都在 `docs/对标截图/<名>/` 里

## 写代码中

- [ ] 组件 registry 定义：icon 指向原版 PNG key（不自创 SVG）
- [ ] C 端渲染：布局/间距/颜色/圆角对照 `01-render.png`，不是凭名字猜
- [ ] 配置面板 schema：对照 `02-props.png`，字段一个不漏
- [ ] 字段联动：对照 `03-notes.md`，`when` 条件正确

## 交付前（不对照不许交付）

- [ ] **并排对照截图**：我的渲染 vs 对标站 `01-render.png`，存 `04-mine-vs-ref.png`
- [ ] **配置面板对照**：我的属性面板 vs 对标站 `02-props.png`，字段/顺序/选项一致
- [ ] 测试通过 + git commit
- [ ] 把未做项（如待接入能力）记到 AGENTS.md 待办清单

## 反模式（出现任何一条立即停下）

- ❌ 凭组件名字/图标猜布局，没点开看对标站实际渲染
- ❌ 抓素材失败一次就降级用本地 SVG/占位图
- ❌ 交付前没并排截图对照，只看"能不能显示"
- ❌ 截图文件不存在就开始写代码
