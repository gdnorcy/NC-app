## 二、写代码时（逐条对照，不许凭名字猜）

- [ ] **schema 字段一个不漏**：对照面板截图，每行字段都有，顺序一致
- [ ] **控件类型对齐系统已有组件**：
  - [ ] 可视化风格/按钮样式选择 → `control:'radio', graphic:true`
  - [ ] 任何带小图标的选项 → `graphic:true` + `img`，不是纯文字radio
  - [ ] 文字选项 → `control:'radio'`（不加 graphic）
  - [ ] 多项内容开关 → ew是checkbox+颜色，拆成 switchColor
  - [ ] 图片上传 → `control:'image'`；开关 → `control:'switch'`；滑杆 → `control:'slider'`；取色 → `control:'color'`；文本 → `control:'input'`
- [ ] **分组标题正确**：
  - [ ] 需要独立小标题用 `group:'标题文字'`，不要把分组标题留成"内容"
  - [ ] 字段归类严格对照ew分组结构，不能想当然把"相关"字段塞一个组
  - [ ] groupDesc要在buildSecs和grpFields两条构建路径都传递
  - [ ] 改完后必须在浏览器里实际看属性面板顺序
- [ ] **图标/缩略图用原版PNG**：registry icon 和 graphic radio 的 img 都指向下载的PNG，不自创SVG
- [ ] **graphic radio UI细节**：有预览图的选项label留空只显示图；选中时不显示勾只留紫色边框
- [ ] **两套渲染同步改**：C端 DesignPage.vue + 设计器 ComponentRender.vue，只改一套会出问题
- [ ] **when联动在画布预览也要生效**：buyBtnShow=0时按钮真的消失，buyBtnText改了文字真的变了
- [ ] **数据字段名核实**：先查API返回的真实字段名（fetch一下看keys），不凭猜写
- [ ] **scoped样式对v-for动态元素可能不生效**：关键尺寸直接用内联style，不靠scoped class
