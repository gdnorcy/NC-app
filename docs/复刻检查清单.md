## 二、写代码时（逐条对照，不许凭名字猜）

- [ ] **schema 字段一个不漏**：对照 `02-props-*.png`，每行字段都有，顺序一致
- [ ] **控件类型对齐系统已有组件**（不许自己发明）：
  - [ ] 可视化风格选择 → `control:'radio', graphic:true`
  - [ ] **任何带小图标的选项**（按钮样式/角标样式/布局样式）→ 也是 `graphic:true` + `img`，不是纯文字radio
  - [ ] 文字选项 → `control:'radio'`（不加 graphic）
  - [ ] 多项内容开关（如"显示内容"9项）→ ew是checkbox多选+每项颜色，先看系统是否有多选控件；没有时才拆成switch+color
  - [ ] 图片上传 → `control:'image'`
  - [ ] 开关 → `control:'switch'`
  - [ ] 滑杆 → `control:'slider'`
  - [ ] 取色 → `control:'color'`
  - [ ] 文本 → `control:'input'`
- [ ] **分组标题正确**：
  - [ ] section 用 `content`/`style`/`member`，对应标签见 PageEditor.vue SEC_LABELS
  - [ ] 需要独立小标题用 `group:'标题文字'`，不要把分组标题留成"内容"
  - [ ] **理解属性面板分组逻辑**：PageEditor.vue `schemaSections` 有两条路径：
    - 无group字段 → `buildSecs` 按 schema 物理顺序建组
    - 有group字段 → grpFields 分组逻辑：topPlain（stylePicker+section=style）→ groups（按group）→ bottomPlain（其余无group字段）→ 通用样式
    - **改完后必须在浏览器里实际看属性面板顺序**，不能只看schema数组顺序就以为对了
  - [ ] **字段不重复显示**：改 topPlain/bottomPlain 过滤条件时，新增的过滤项要从另一处排除，否则字段会出现两次
  - [ ] **改公共渲染逻辑（graphic fallback/分组过滤）前，先确认不影响已有组件**（如富文本），改完并排对比已有组件未变样
- [ ] **图标用原版PNG**：registry icon 指向下载的图片文件，不自创黑色SVG
- [ ] **缩略图用ew原图**：graphic radio 的 option 加 `img` 字段引用下载的PNG，不用手绘线框图
- [ ] **graphic radio UI细节**（和系统已有graphic组件对齐）：
  - [ ] 有预览图的选项**不显示文字标签**（label留空），只显示缩略图
  - [ ] 选中时**不显示右上角勾**，只留紫色边框高亮
  - [ ] 纯文字选项（默认/投影/描边等）才显示文字label
- [ ] **样式选择器（默认/投影/描边）复刻要求**：
  - [ ] 用 `control:'radio', graphic:true`，和系统已有富文本组件一致
  - [ ] **放在属性面板最前面**，上方加"样式"分组标题
  - [ ] 不擅自改fallback SVG渲染逻辑（改了会影响富文本等已有组件）
- [ ] **选择风格/图形选项复刻要求**：
  - [ ] 必须下载ew原版缩略图PNG到本地（`web-admin/src/assets/design-thumbs/`），registry里import后用thumbMap映射
  - [ ] 不手绘线框图、不自创SVG、不用本地图标库近似图
  - [ ] option的label留空（只显示图，不写"风格1"）
  - [ ] 风格数量必须数DOM确认，不靠眼睛估
- [ ] **两套渲染同步改**：C端 `DesignPage.vue` + 设计器 `ComponentRender.vue`，只改一套会出现"C端对了设计器空"
  - [ ] **画布预览必须根据属性动态渲染**：不是写死的占位文字。每个schema字段的变化都要在画布预览看到效果
  - [ ] **when联动在画布预览也要生效**：buyBtnShow=0时按钮真的消失，buyBtnText改了文字真的变了
  - [ ] **C端渲染也要同步**：DesignPage.vue里购物车按钮也要按buyBtnStyle/Text/Color/Radius渲染
- [ ] **catch 不静默吞错**：数据加载失败必须可见，不能 UI 变空态
- [ ] **不擅自降级**：对标有但本地数据缺的字段，保留字段+默认值，向用户标注"待接入"，不许删掉或换成占位
- [ ] **数据字段名核实**：组件要加载已有数据（商品/分类/文章等）时，先查API返回的真实字段名（bu.js里fetch一下看keys），不凭猜写g.image/g.title。常见坑：商品图字段是thumb不是image
- [ ] **picker类控件必须传fieldKey**：openLinkSel/picker调用时第三个参数必须带key（如{pickerMode:'goods', key:'goodsIds'}），否则confirmLinkSel不知道写回哪个字段
- [ ] **scoped样式对v-for动态元素可能不生效**：v-for里渲染的列表项/缩略图，关键尺寸直接用内联style，不靠scoped class。:deep()也不一定管用
- [ ] **交互链路也要对照**：不只是视觉1:1，点击弹窗→选择→确定→写回→显示缩略图，整条链路都要在ew实测一遍，在我们系统走一遍
- [ ] **picker弹窗模式分支**：mode='goods'/'cat'时，LinkPicker必须有专门的列表模板分支，不能fallback到"自定义链接"输入框。cat模式显示分类列表，goods模式显示商品列表
- [ ] **picker选了后显示名称而非ID**：分类/分组选择后，readonly框要显示名称（catCache/id→name映射），不能只显示数字ID
- [ ] **switchColor类控件label不重复**：el-form-item已有label，模板里不要再加span显示f.label，否则出现"商品标题 商品标题"
- [ ] **switchColor开关样式用el-switch**：不是el-checkbox，对齐ew的蓝色toggle样式（和标题标签/会员价/新人价一致），不要用带勾的checkbox
- [ ] **分组标题desc传递**：group标题带说明文字时，groupDesc要在buildSecs和grpFields两条构建路径都传递（PageEditor.vue有两条分组构建逻辑，改一条另一条漏了desc就不显示）
- [ ] **字段归类严格对照ew分组结构**：不能想当然把"相关"字段塞到一个组里。ew里"选择商品"和"显示内容"是两个独立分组，必须逐行对照截图确定每个字段属于哪个group
- [ ] **已选商品缩略图排列**：横向flex-wrap排列，小方块+红色×删除按钮+"+添加"虚线框同行，不是竖排大缩略图
