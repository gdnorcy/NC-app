# 复刻新组件/新功能强制流程

**复刻任何新组件/新页面/新功能前，必须先读 docs/复刻检查清单.md，逐条打勾后才允许写代码。**
截图存 docs/对标截图/<组件名>/，没有截图就不动笔。这是硬规则。

## 复刻装修组件时的额外注意
- **必须同时改两套渲染**：C端 DesignPage.vue + 设计器 ComponentRender.vue，只改一套会出现"C端对了但设计器预览空"
- **图标必须用对标站原版PNG**，禁止凭语义自创SVG
- **字段全集/默认值/联动条件以对标页DOM实测为准**，禁止凭名字猜
- **本地数据缺失不是降级理由**：先补数据或向用户说明，禁止静默降级
