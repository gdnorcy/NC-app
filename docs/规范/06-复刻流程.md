# 复刻新组件/新功能强制流程

**复刻任何新组件/新页面/新功能前，必须先读 `docs/复刻检查清单.md`，逐条打勾后才允许写代码。**
这是硬规则，不是建议。没截图、没数DOM、没抓原版素材 = 没开始。

## 核心铁律（违反任何一条立即回炉）

1. **素材抓原版**：图标/缩略图从对标站DOM抓URL下载PNG，禁止自创SVG/手绘线框图
2. **数量数DOM**：风格数/选项数用 `document.querySelectorAll(...).length` 确认，不靠眼睛估
3. **字段截全量**：配置面板从上到下滚动截全，展开所有子选项/tab
4. **控件类型对齐**：新组件control类型参考系统已有组件，不许发明新类型
5. **两套渲染同步**：C端 DesignPage.vue + 设计器 ComponentRender.vue 都要改
6. **交付并排对照**：我的渲染 vs 对标截图并排保存，字段数一致
7. **catch不静默吞错**：数据失败必须可见
8. **不擅自降级**：对标有但本地缺的字段保留+标注待接入，不删
