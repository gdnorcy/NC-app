### 4. `fill="currentColor"` 黑色回退——「孔洞糊死」的真因

**这才是开发者工具里「图标和之前不一样、变得很难看」的主因。**

| 项 | 说明 |
|---|---|
| 现象 | `apps` 九宫点 9 个点中心带黑洞、`radar` 同心圆中心黑洞、`dynamic` 气泡 3 点带黑洞 |
| 涉及图标 | `apps` `radar` `dynamic` `wallet` `storage` `wechat`（共 6 个用 `fill="currentColor"`） |
| 根因 | 根 `<svg>` 只有 `stroke`，**没声明 CSS `color`**；子元素 `fill="currentColor"` 覆盖父级 `fill="none"` 后，按 SVG 规范回退成**黑色** |
| 修法 | 根 `<svg>` 补 `color="<描边色>"` 属性（**两处**：H5 data URI + 小程序 PNG 模板） |

```diff
- fill="none" stroke="#ffffff" stroke-width="2"
+ fill="none" color="#ffffff" stroke="#ffffff" stroke-width="2"
```

**判定口诀（下次直接用，别再走弯路）**：

- 描边图标（`crown` `dist` `card` `market`…）→ `stroke-width` **有效**，粗细影响观感
- 实心点图标（`apps` `dynamic` `radar` 中心点）→ 靠 `fill`，**`stroke-width` 完全无效**
- 看到「点/孔洞糊成一坨」→ **先查源码是 `fill=` 还是纯 path**，不要先动 `stroke-width`

**本轮弯路记录**：最初误判为「描边随显示尺寸等比放大（43px时等效 3.58px）> 内部间隙 4.3px
→ 糊死」，为此实现了完整 `strokeWidth` prop + 宫格自适应描边（43px → 1.3）+ 生成脚本白色变体
（509 条 base64），跑了两轮 4 分钟构建 —— **结果实心点完全没变化**，全部回滚。
真正的修复只有 1 行 × 2 处。

### 5. 与方案 v5 的规格偏差（本轮）

用无头浏览器渲染 `名片宫格图标方案.html` 与真机截图并排比对，找到 3 处偏差：

| 项 | 方案 v5 | 修复前 | 处理 |
|---|---|---|---|
| 会员中心图标 | **对勾圆**（圆环＋对勾） | 皇冠（`3f0208c` 改的） | ✅ 回归 v5 |
| 「更多」底色 | `#78909c→#546e7a` 灰蓝 | `#13c2c2→#00d0c7` 青绿（`fc607ab` 改的） | ✅ 回归 v5 |
| 框内图标比例 | 46px 框 + **32px** 图标（占 70%） | 43px 框 + 40px 图标（占 93%，撑满） | ✅ 解耦为 46/32 |

**尺寸耦合的根因**：`home.vue` 的 `gridIconSize()` 直接返回 `iconSize`，
导致「方块大小」和「图标大小」是同一个值 —— 图标必然撑满方块，描边被挤到边缘。
现已解耦：`GRID_ICON_RATIO = 32/ 46`，`iconSize` 只控方块，图标按比例内缩。

**方案 v5 的完整规格**（从文档 CSS 提取，`docs/规范/名片宫格图标问题清单.md` 备查）：

```css
.icon      { width: 46px; height: 46px; border-radius: 14px }  /* 方案 A 圆角方形 */
.icon svg  { width: 32px; height: 32px }                       /* 图标占框 69.6% */
--gap: 10px                /* 宫格间距 */
stroke-width: 2            /* 描边，规范值 */
```

方案 A/B/C **三档只有底色不同，9 个图标路径完全相同**（已用浏览器渲染 + 截图确认）。
用户 2026-10-05 选定**方案 A（品牌多彩渐变）**。

### 对照方法（可复用）

方案类 HTML 文档**不要用正则提取 `<svg>` 内部路径**—— 方案原文里存在
「标签名与属性名之间空格被吞」（`<rectx="1.5"`）、`path` 缺自闭合斜杠等残缺 HTML，
正则修补反复失败。**直接用无头 Chrome 渲染截图**，肉眼看最可靠：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-sandbox --use-gl=swiftshader --in-process-gpu \
  --screenshot=/tmp/out.png --window-size=1200,900 --hide-scrollbars "file:///path/to/方案.html"
```

注意：必须加 `--headless=new --use-gl=swiftshader --in-process-gpu`，
旧 `--headless` 会因 GPU process 不可用直接崩溃。
