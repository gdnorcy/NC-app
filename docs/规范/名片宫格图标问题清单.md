### 1. 宫格图标渲染分辨率不足 —— 真凶，已修

| 项 | 值 |
|---|---|
| 根因 | `gen-mp-sicons.js` 固定产出 **24×24** PNG |
| DB 配置 | `iconSize: 43`（比默认 40 还大） |
| 拉伸倍数 | 24 → 43 = **1.79 倍** |
| 后果 | 描边边缘发虚有毛刺；`apps` 九宫点糊成一团 |
| 证据 | 你的两张截图裁同一图标放大对比：**形状完全相同，差别只在清晰度** |
| 修法 | 分级渲染：宫格等大尺寸场景 29 个图标 → **72px**（1.67倍余量），其余 31 个保持 24px |
| 代价 | base64174.6 → 259.7KB（**+85.1KB**）；主包 1355 → **1441KB = 1.41MB < 1.5MB 通过** |

**这一项是「难看」的主因，已修复，重新预览小程序即可验证。**

### 找历史方案的正确顺序（三轮失误的根治办法）

1. `git log --follow <核心文件>` —— 看**全部**变更史（`--follow` 才追得到跨文件的早期提交）
2. `git log -1 --format=%B <hash>` —— 读提交**正文**（方案名常写在正文而非标题）
3. 找**仍存在的原始产物**目录 —— 代码比文档权威
4. 最后才翻文档 —— 文档可能是二手的
