## 一、已修复

### 1. 宫格图标渲染分辨率不足（`37022a0`）

| 项 | 值 |
|---|---|
| 根因 | `gen-mp-sicons.js` 固定产出 **24×24** PNG |
| DB 配置 | `iconSize: 43` |
| 拉伸倍数 | **1.79 倍** |
| 修法 | 分级渲染：29 个大尺寸图标 → **72px**，其余 31 个保持 24px |
| 代价 | base64 174.6 → 259.7KB；主包 1441KB（1.41MB，通过） |

**这是「难看」的主因。**

### 2. C 端兜底数组与方案 A 不一致

`home.vue` 的 `features` 兜底数组仍是项目初版（`501fcfe`）旧配色，
`b91ef52` 定稿时只改了设计器与 DB，**漏改了 C 端**。
已同步为方案 A 9 色 + `distribution` 图标改 `dist`。

### 3. 设计器「更多」底色错误（本轮新发现）

`componentRegistry.js` 中「更多」是 `#78909c` 灰蓝，但方案文档与 DB 均为 `#13c2c2` 青绿
——设计器默认值本身与方案不符。已修正。

**现三方 9/9 完全一致**（componentRegistry / DB / C端 features）。

## 二、已撤销的错误改动（重要）

**曾把 9 个宫格图标回退到 `static/icons/*.svg` 旧版（`e15a1c6`），已 revert（`a5e21ca`）。**

原因：误把 `static/icons/*.svg`（`24f4017` 的 2px 描边规范产物）当成「宫格定稿版」，
**但 v5 方案文档证明宫格图标在 9/26 已独立定稿，且刻意做得更精细。**

**教训**：项目里有**两套并存**的图标规范，勿混：

| 来源 | 风格 | 适用范围 |
|---|---|---|
| `static/icons/*.svg`（`24f4017`） | 2px 描边、简洁 | **全局图标规范**（导航/按钮等通用场景） |
| `名片宫格图标方案.html` v5 | 元素更多、更贴业务 | **名片宫格专用**（9 宫格） |

宫格以 v5 方案为准，**不是** `static/icons`。
