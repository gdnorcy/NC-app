# 商城规范

## 金额口径（强制）
- 商品列表/详情 price=元；购物车 cart price=分；订单/支付 amount=分
- 前端统一 fen2yuan（分→元）/ yuanFmt（元→元字符串），禁止混用

## 商城装修页固定头部
- /pages/mall/index 页面级固定头仅在无装修组件时显示；designComps.length>0 时必须隐藏
- 预览URL必须走真实C端入口（/mall/#/pages/mall/index），禁止用通用装修容器

## 首页跳转按应用维度化
- 存储：tenant_home_config.home_pages（JSON {appCode:路径}）
- 接口：GET /api/customer/design/home/get、POST /home/save
- 管理端：DesignHome.vue 按 HOME_APPS 清单每应用一行
- C端：web-app/src/utils/design.js normalizeDesignConfig 取 homePages.card ?? homePage

## 装修组件联动内容管理
- article-list source=content 拉 contentArticles；pic-list 拉 contentPics；video-list 拉 contentVideos
- 数据链路：管理端保存草稿→tenant_page_design→C端/api/card/design/config→DesignPage渲染

## 待接入能力（字段保留，禁止删除）
- 超级表单「红包封面」（useFormId=1）：需新建超级表单应用
- 客服选择「小东」（cusId=1）：需接入微信客服
- 接入时必须先提醒用户确认
