# 历史问题与预防规范

## 前端渲染类
- **问题3**：API前缀重复+响应解包误用→页面空态。新页面先看 api/index.js 的 baseURL
- **问题4**：组件内联 template 字符串在 vite runtime-only 构建下不编译→渲染为空。**禁止 template: 字符串定义组件**，用 h()/JSX
- **问题5**：接口返回结构假设错误+catch静默吞错→UI静默变空。**catch禁止静默吞错**，数据决定内容的失败必须可见
- **问题8**：<script setup>漏import Vue API→运行期ReferenceError被外层catch吞掉。用到什么必须显式import什么
- **问题12**：内层height:100%、外层漏设高→DOM存在但视觉塌陷。内层用100%外层必须显式设高

## 数据/缓存类
- **问题9**：C端验证被SW/强缓存旧chunk蒙蔽。同步产物必须删旧再拷；验证前清SW+缓存破坏参数
- **问题10**：API响应ETag/304→uni.request拿到空body。**API必须禁用ETag**（app.disable('etag')）
- **问题11**：uni H5 storage与localStorage直写不同步。读登录态统一走getToken()

## 菜单/组件类
- **问题6**：二级菜单key与compMap映射键不一致→误挂开发中占位。key必须与compMap严格一致
- **问题7**：对标字段级联数据缺失时擅自降级。对标层级必须1:1还原，禁止静默降级；区县级用AREA_DATA_FULL
- **问题13**：复刻组件图标擅自自创SVG。**图标必须用对标站原版PNG**，禁止凭语义从本地SVG库挑

## 部署类
- **问题1**：旧版本HTML残留→express.static返回旧文件。迁移后必须删旧入口+301重定向
- **问题2**：SW缓存管理后台。SW必须排除/admin、/customer路径
