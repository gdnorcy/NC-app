# ew 商品组件实际配置参考（1:1复刻依据）

## 1. 商品组 (goods-group)

### 渲染结构
- 单列列表，每项左图右文
- 上方商品图（大图区域）
- 下方：红底白字小标签"标题标签" + 黑色商品标题
- 副标题（灰色 #999ca7）
- 左下角：红色价格 #fd463e "¥20/件"
- 右下角：红色圆角按钮"购买"（背景跟随主题色，圆角4px，尺寸小）

### 配置参数
- **样式**：默认/投影/描边
- **选择风格**：6种缩略图（当前第1种=左图右文）
- **选择商品**：全部商品/选择分类/选择分组（单选）+ +添加按钮
- **底部背景**：transparent
- **商品背景**：#fff
- **显示内容**（多选，优先级：新人价>会员价>划线价）：
  - ☑ 商品标题 #37383A
  - ☑ 副标题 #999ca7
  - ☑ 商品价格 #fd463e
  - ☐ 划线原价 #999CA7
  - ☐ 商品销量 #999CA7
  - ☐ 会员价
  - ☐ 新人价
  - ☑ 标题标签
  - ☐ 商户名称
- **购物车按钮**：
  - 显示/隐藏
  - 样式：4种（圆角矩形"购买"/圆形+/方形购物车/圆形购物车）
  - 文字："购买"
  - 颜色：transparent
  - 圆角：4px
  - 背景：跟随主题风格/自定义
  - 边框：transparent
  - 尺寸：小/中/大
- **点击购物车按钮**：进入商品详情页/商品加购
- **角标设置**：不显示/系统图标/自定义
- **边距设置**：上下左右/上下圆角

### 配置参数
- **样式**：默认/投影/描边

- **选择商品**：全部商品/选择分类/选择分组
- **排序**：按上架时间倒序/正序/按访问量
- **底部背景**：transparent
- **商品背景**：#fff
- **显示内容**：同商品组
- **购物车按钮**：同商品组
