# UI 设计规范

> ⚠️ **适用范围**：本节图标规范**仅适用于装修面板 + 超级表单**，**不含名片宫格**。
> 名片宫格（首页 9 宫格 / 应用中心）目前是「白描边图标 + 彩色渐变方块底」，
> 与本节「填充风 + 透明底」不一致，属**已知风格分歧**，尚未统一 —— 见下方「已知分歧」。

## 组件图标风格（装修面板 + 超级表单统一）

### 配色（三层蜜桃橙，不是单色）

- 浅橙 `#ffc4a8`：大块底色/外框/主体填充
- 标准橙 `#ff8a6a`：中间层/次要元素
- 深橙 `#f0503a`：强调/重点/中心/勾选

### 视觉语言

- **填充为主**，不是描边线条；对齐 `web-admin/src/assets/comp-icons/` 下原版 PNG（form/picture/notice/countdown）
- **大圆角扁平**，无描边、无渐变、无阴影
- **透明底**，不套彩色方块（禁止绿/紫/蓝分类底色）
- **每图标内部由三层橙红组成**：浅橙底 + 标准橙中间层 + 深橙强调，不是整个图标一个色

### 参考实现

- 装修面板原版 PNG：`web-admin/src/assets/comp-icons/*.png`
- 设计参考稿：`superform-icon-plan4.html`（仓库根目录）

### 禁止

- ❌ 自创 SVG 线条风格（描边为主）
- ❌ 绿/紫/蓝三色分类方块底
- ❌ 外框用描边线而不是浅橙填充块
- ❌ 一个图标只用一个颜色

## 已知分歧

### 名片宫格图标风格（未统一，待决策）

- **现状**：`web-app/src/pages/cardMain/home.vue` 首页 9 宫格用「白色描边图标 + `linear-gradient(135deg,…)`
  彩色方块底」，描边风与本节「填充为主 + 透明底」相反。
- **未统一原因**：本节规范制定时未覆盖宫格场景；改动涉及 9 个图标 + 三端一致性（web-app /
  web-admin / 设计器预览）+ 渐变底色配置项，牵涉面较大。
- **待决策**：是否改为填充风。若维持现状，建议在此补一节宫格专属规范，避免后续误判为"违规"。

### 宫格图标渲染分辨率（已修，供后续参考）

- 历史问题：`scripts/gen-mp-sicons.js` 固定产出 24×24 PNG，而宫格 `iconSize` 默认 40px
  → 24px 拉伸 1.67 倍显示，描边发虚、密集细节（如九宫点）糊成一团。
- 现方案：**分级渲染** —— 宫格等大尺寸场景用的图标出 72px，其余保持 24px。
  全量提到 72px 会因 PNG 面积随边长平方增长（9 倍像素）把主包 base64 从 175KB 推到 ~1.5MB，主包必爆。
- 改动渲染分辨率后**必须重跑 `node scripts/gen-mp-sicons.js`**，否则小程序端仍用旧 base64。
- 统计主包体积时**只能算一次总量**（排除 4 个分包前缀即可），不要按目录分组统计——
  `static/sicons` 目录会被重复计入，导致虚高 383KB。
