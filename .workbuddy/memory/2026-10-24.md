## #312 第十八轮：登录不再跳两次页面（改为页面内原地登录）

反馈：「现在登录要跳两次页面」。链路：`我的名片`(未登录) → reLaunch 到
`pages/cardMain/login` → 登录完再 reLaunch 回名片页，**去、回各一次跳转**，
用户看着两个页面各闪一遍。

修法（通用思路：别用「跳出去再跳回来」触发状态刷新）：
1. 登录请求收敛到 **`utils/inlineLogin.js`**（`fetchLoginCode` / `performWxLogin` /
   `mustCreateCard`），登录页与页面内浮层共用一份——否则 H5 模拟码、租户兜底
   `DEFAULT_TENANT_ID`、登录后 `resetBrandCache` 三条任一条漏写就是「能登录但首页空白/品牌色不对」。
2. 新组件 **`components/LoginGate.vue`**：未登录占位视图里直接放「微信一键登录」+ 协议文案，
   点一下就地登录（busy/inflight 双闸防连点——微信 code 一次性）。
3. myCard 把 `onMounted` 里的进入流程抽成 **可重入的 `bootOwner()`**，登录成功后
   `notLogin=false → await bootOwner()` 原地进入；**0 次跳转**。
   只有 `mustCreateCard`（新用户/没名片）才跳一次 `/pages/card/create`（否则落在空壳页）。

踩坑与教训：
- 既有 `brand.test.js` 钉的是「login.vue 必须 import resetBrandCache」这种**写法**，
  实现搬走就红。改钉**语义**：inlineLogin.js 调了 resetBrandCache + 两条入口都走 performWxLogin
  + 入口里不许再出现 `cardApi.wxLogin(`。
- 模板里 ref 不带 `.value`（写 `busy.value ? …` 在模板里不生效），测试断言也要按模板形态写。
- MP 端确认三处齐全才算挂上：`components/LoginGate.{js,json,wxml,wxss}` +
  页面 `myCard.json` 的 `usingComponents` + wxml 里的 `<login-gate bindsuccess=>`。

## #312 第十八轮 b：动态页一并原地化（用户："那还是一并原地化好"）

把 `pages/card/dynamic.vue` 的登录也改成原地化，但比 myCard **多一层**：
动态页的「发布 / 编辑」是**动作**，老实现点一下就被 reLaunch 弹走，登录完回来
还得**再点一次**——这才是用户抱怨的另一半。

修法（通用范式，已写进 MEMORY「登录与跳转体验」）：
1. 进入流程抽成可重入 `bootDynamic()`（onMounted 与登录成功共用）。
2. 守卫从同步 `ensureLogin()` 改成**返回 Promise 的 `requireLogin()`**：
   `if (!(await requireLogin())) return;` → 登录成功**自动继续执行原动作**。
   `cancelLogin()` 必须 `gateResolve(false)`，否则 await 永远挂住（按钮"点了没反应"）。
3. `onMounted` 未登录只弹浮层 + return（保留列表的「暂无动态」作背景）；
   `onShow` **不无脑弹走**——只在「已加载过内容 && 登录态掉了」时补弹。
4. 浮层 `.lgmask/.lgsheet`：居中白卡（区别于发布弹窗的底部 sheet），
   遮罩 `var(--bg-mask)`、层级 `var(--z-popup)`，不新增裸 z-index / rgba 字面量。

踩坑：
- 三份旧测试（`dynamicRound7` / `dynamicRound9` / `dynamicSheet`）钉的是
  `function openPublish() { if (!ensureLogin()) return;` 这种**写法**，守卫一改就红 5 条。
  改钉语义并保留反向钉死（`not.toMatch(/function ensureLogin/)`），防后人把跳转加回来。
  → 与 18 轮 brand.test.js 是同一类坑：**实现一收敛，钉写法的测试就红一片**。
- 校验 MP 产物时 `grep -o "暂不登录\|登录后继续"` 又返回 0 —— **BSD grep 不支持 `\|`**，
  文件里其实有（分别 grep 各得 1）。这条今年第 6 次踩。
- `LoginGate.wxml` 里没有「微信一键登录」字面量：MP 编译把三元折成 `{{a}}`，
  字符串落到 `components/LoginGate.js`。可见文案要么在 wxml 要么在 js，**别只查一处**。
