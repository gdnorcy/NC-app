## 创建页头部/按钮改纯色（v3.3）
- **需求**：用户反馈创建页绿色区域「渐变不太美观」，改纯色。
- **改动**：`web-app/src/pages/card/utils/createSkin.js` 的 `--sk-header`/`--sk-btn` 由 `linear-gradient(180deg, accent, gradEnd)` 改为纯 `accent`。历程：v3.1 透明化被否 → v3.2 恢复渐变（135deg→180deg）→ v3.3 纯色。
- **关键决策**：文字对色判据**不改**——仍走 `heroForeground(accent, gradEnd)` 渐变中值口径。原因：① 全仓唯一裁决口不能自造第二套；② 灰区主色（浅金 #c9a25e luma≈166）若按纯主色判会落白字（白/浅金对比仅 2.4:1 不可读），中值口径（≈199>180）正确落深字（6.8:1）。gradEnd 保留专供判据。
- **测试**：`createSkin.test.js` 新增纯色锁定断言（`toBe(primary)` + `not.toContain('gradient')`），注释同步 v3.3；`createColorSystem.test.js` 注释更新。web-app 全量 857 例全绿。

## 「进入客户」报错修复（数据问题非代码）
- **现象**：服务器 admin 客户页点「进入客户」报「该客户下暂无可用账号，请先在用户管理中创建客户项目账号」。
- **根因**：`server/src/routes/customers.js:333` impersonate 找 `users WHERE customer_id=项目id AND role=tenant_admin AND status=active`。**服务器 DB 只有 admin 一个用户**——`db.js` 种子只建 admin（config.adminUser），从不建租户口；本地 dev 库的 tenant1/entmgr1 是开发时手动建的，部署快照没带上。`seed-card-demo.js` 只消费已有租户口不建号。创建客户（POST /projects）也不自动建号——设计上就要去「用户管理」单独建。
- **修复**：TAT 在服务器用服务端自己的 `hashPassword`（`db.js` 导出、无顶层副作用，import 安全）插入 `tenant1`/`admin123`/tenant_admin/customer_id=1/active。登录接口实测 200 签发 token（customerId=1），impersonate 查询条件即命中，无需重启。
- **教训**：新部署服务器默认进入不了任何客户——这是数据缺口，不是 bug；本地→服务器的 DB diverges 要从部署第一天就放在心上。

## 服务器数据库同步（本地→服务器，测试用）
- **背景**：服务器库是首次部署时新建的（只有 admin + 种子目录数据，`tenant_page_version` 0 行），装修页面无数据。本地库 2.1MB 含 6 条装修版本、13 张名片、3 个用户。
- **同步协议**（可复用）：① Python `sqlite3` backup API 做一致性快照（本地服务在跑也不撕裂）；② 快照内**保留服务器 admin 的 hash/salt 原样**（用户无感知，不至于被锁），租户口 tenant1/entmgr1 密码重置为 admin123（本地库原密码已不可考）；③ uploads 一并打包（5.5M）；④ 推临时分支 `db-sync-tmp` 传文件 → 服务器停服、mv 备份旧库（`panorama.db.bak-20261017-002654`）→ 下载换库 → 解压 uploads → 重启 → **删临时分支**（不让库文件长期留在仓库）。
- **通道坑**：raw.githubusercontent.com 直连 280s 只下 87%（5.3M 超时）→ 改走 ghfast 镜像 `git fetch <mirror> db-sync-tmp` + `git checkout FETCH_HEAD -- path`，秒完。Mac 本机 curl raw 报 SSL 错（exit 35）是本地网络问题，与服务器无关。
- **验证**：服务器 `tenant_page_version` 6 行 / `card_profile` 13 行；tenant1 登录 200；`/api/card/design/config?id=1` 返回 11KB 真实配置（此前为空）；admin/card/mall 外网全 200；服务日志有真实访问流量。
- **服务以 root 运行**（systemd User=root），换库无需 chown。旧库备份在服务器 `/opt/app/server/data/panorama.db.bak-20261017-002654`，要回滚随时可换回。
