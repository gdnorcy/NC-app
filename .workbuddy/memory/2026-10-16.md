## 修复 ColorSystem 锁测试的两个坑（后续 token 化批次必看）
1. **负向断言不能加 var 备选**：改写锁测试时，正向 `toContain('#hex')` 可转 `toMatch(/#hex|var\(--token\)/)`；
   但负向 `not.toContain(c)`（banned 颜色必缺席）**绝不能**转成 `not.toMatch(/c|var\(--token\)/)` ——
   因为 CSS 里任意 `var(--x)` 都会命中 var 备选，导致负向断言误报失败。正确做法：负向保持 `not.toContain(c)`。
2. **四连杠 bug**：脚本生成 `var(----token)`（MAP 值已含 `--` 前缀又叠加一次）→ 应是 `var(--token)`。
   机械替换时按 `var\(----` → `var\(--` 全量替换即可（幂等，不影响已正确的两连杠形式）。
