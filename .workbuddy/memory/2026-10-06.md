# 2026-10-06 工作日志

## 按钮组三条新反馈（commit `febf7f4`）

### 1. 标签（角标）尺寸参数
- 样式区新增 `markSize`(10~28, 默认14=实测视觉值) 与 `markFontSize`(6~16, 默认8)，
  组件级（对标站没有，用户要求增强）；`when: navStyle∈[style1,style2]`（角标只出现在图区）。
- `menuGroupStyle.js menuMarkStyle(it, p)` 改签名：发射 height/line-height/font-size，
  **p 缺省回落实测默认值**（两端 CSS 基础值一致，存量数据零变化）。
- 两端渲染同步接参：C 端 `menuMarkStyle(it, c.props)`（2 处 text）、画布 `menuMarkStyle(it, comp.props)`（span）。
- ⚠️ clamp 必须写：Math.round + min/max，否则非法值直接进 inline 样式。
- 实测：键盘步进滑杆（el-slider button focus + ArrowUp keydown）14→28 / 8→16 后，
  画布 `.mg-mark` computed height 14px→28px、font-size 8px→16px。

### 2. 图标设置左右排列
- list 字段新增 **`inline`** 标记（**不要复用 `compact`**——compact 会同时改变 PeImagePicker
  的图片选择器排版，mini 的 40×40 方框规则就是 `:not(.pe-img--compact)` 圈定的）。
- PageEditor 两处 list 模板 `:class="[compact?'pe-list-compact':'', inline?'pe-list-inline':'']"`；
  CSS：`pe-list-inline { flex-direction:row; align-items:center; gap:8px }` + label 56px 固定。
- 实测：7 个字段全部 row、垂直中心同排（⚠️ 验证要比较 **centerY** 不是 top，
  align-items:center 时高度不等的两个盒子 top 必然不同）。

### 3. 图形化 radio 标题 + 按钮样式示意图重画
- 模板 label 表达式：`(radio && graphic && !f.graphicLabel)` 才吞 label；
  `pe-label-top` 条件加 `(radio && graphic && f.graphicLabel)`。
- registry：navStyle/navShape 加 `graphicLabel:true, graphicSmall:true`；navStyle 三档各带 `menuStyle` 值。
- 新增 `o.menuStyle` SVG 分支（放在兜底 v-else **之前**）：图片+文字=蓝块+灰线 / 仅图=蓝块 / 仅文字=蓝线；
  **蓝色块 = 该档位实际渲染的部分**。`pe-graphic-sm`：svg 56px→36px 高 + item padding 收小。
- ⚠️ 用户原话「第二个红框加按钮类型」但第二排是形状（方形/圆角/圆形），且下方已有「按钮类型」行
  ——按语义落成「按钮形状」，避免与既有「按钮类型」重复，需向用户说明这一取舍。
