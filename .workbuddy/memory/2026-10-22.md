## #327 按钮/公告/搜索框「对齐 + 左边偏移」改口径（已完成并上线）
- 用户口径（原话）：**对齐=基准，左边偏移=叠加在基准上的微调，手动切换对齐→偏移清零。**
- 🔴 病根：偏移用 `margin-left` 表达，直接**覆盖** `applyAlign` 写好的 `margin-left:auto`
  → 居中/居右当场失效（看起来都像居左）；且偏移 ≠ 0 时 marginLeft 每次都被覆盖，
  **切对齐界面毫无反应** —— 用户说的「三个参数感觉不太对」就是这个。
  ✅ 改 `position:relative + left`（不碰 margin、不改宽度、不造层叠上下文）。
- 新增共享 `utils/boxAlignOffset.js`：ALIGN_OPTIONS / normalizeAlign / offsetShiftStyle /
  clearedOffsetsFor / ALIGN_OFFSET_KEYS=['boxOffsetX','offsetX']（两个历史 key 都要认）。
- `searchBoxSizeStyle` 删掉写死「marginLeft:0; marginRight:auto」那两行（原注释已预告
  「将来加 align 时这行会把它拽回左边」）→ 尊重 align；`defaultAlign:'left'` 保存量视觉。
  ⚠️ 搜索框 align 的效果是「框在**铃铛左侧那片空间**里的位置」，铃铛始终贴右。
- native-search 只在 **admin** registry（C 端 cardCompRegistry 无此类型），故 align 只加一处。
- 面板：cardEdit `onRadioPick(f,val)` / admin `setProp` → key==='align' 且值真变化时清偏移。
- 坑：写「两端不许内联 label:'居左'」这类断言会误伤 `textAlign`（占位文案对齐，同三选项但
  语义不同）与图文的「文字对齐」（只有左/中）→ 断言要按字段语义过滤，别全文否定。
