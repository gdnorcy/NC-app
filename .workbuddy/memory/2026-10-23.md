## #312 动态发布 第四轮 7 项真机反馈（已上线）

部署：main `2ab7c3d5`（源码）→ deploy `25b4359d`(merge) + `cac7f006`(产物) → 远程 reset +
重启（MainPID 1998695 running）。线上入口 chunk 与 dynamic/cardDetail chunk md5 均与本地一致。

七项反馈 → 根因 → 修法：
1. **正文图没压缩**：原先只靠 `chooseMedia sizeType:['compressed']`（H5 端等于没有）。
   → 把 `compressCover` 抽成通用 `compressImage(src,{square,max,quality})`；封面 square:true
   （120rpx 方图），正文 square:false + 长边 1280 + JPEG 0.85。`pickImages` 上传前走压缩，
   压缩失败 try 兜底原图直传（不能阻塞发布）。
2. **新动态带上一条内容**：`closePublish` 只清开关类状态、**没清表单**——只有发布成功路径才重置。
   → 抽 `resetForm()` + `emptyDynamic()`，**打开/关闭/发布成功三处都调**。
3. **看不到封面入口**（用户裁决「两个都要」）：①链接卡片封面原先深埋在默认收缩的分区里 →
   提到分区头右侧（有图显示缩略图 / 无图显示「＋封面」，`@click.stop` 避免顺带切换展开态）；
   ②新增**动态自己的封面头图** `cover` 字段（db 迁移 + INSERT/UPDATE + toDynamic +
   前端上传入口 + 两处列表展示）。cover 与 link_img 是两个东西，且 cover **不参与**
   图片/链接/引用三选一互斥（头图是整条动态的门面）。
4. **分区展开拥挤**：展开体整块包进 `.sec-panel`（浅底卡片 + padding + gap）。
5. **已选图无预览 / 9 张全铺**：≤3 张九宫格，>3 张改 `scroll-view scroll-x`（仅发布弹窗）；
   点图 `uni.previewImage`。
6. **定时发布后页面滚不动**（滚动穿透）：mask `@touchmove.stop.prevent` + sheet
   `@touchmove.stop`，**必须成对**——只写 mask 的话 sheet-body 的滚动会冒泡到 mask
   被一起 preventDefault，弹窗内也滚不动。
7. **名片详情只显示一张**（写死 `d.images[0]`）→ 重叠堆叠最多 3 层 + 剩余「+N」角标，
   容器必须**定高**（绝对定位子层不撑高父容器，没高度会塌成 0）。
   图片底下**两个 0 是 likeCount/commentCount 计数**，不是漏东西。

## 本轮踩坑（新元规则）

- 🔴 **H5 构建后必须额外跑 `node scripts/sync-mobile-dist.mjs`**：`build:h5` 只输出到
  `web-app/dist/build/h5`，**不会**同步到 `server/public/{card,mall}`（只有 build:mp-weixin
  内联了 sync-mini-template）。漏这步 → server/public/card 仍是旧产物，
  grep 特征串全 0，「构建成功但线上没变」。
- 🔴 **`cp -a 备份目录 目标目录` 在目标已存在时会嵌套**（checkout -f deploy 后产物目录被还原
  成旧版，于是变成 card/card/）。正确做法：先把目标整个 `mv` 到 /tmp（rename 无 safe-delete
  守卫），再 `cp -a` 铺过去。嵌套后自检 `grep 特征串` 会全 0，是唯一的快速判据。
- 🔴 **tokenAudit 基线不许上调**（rgba 288 / shadow 46 / z 27 / hex 574）：新增裸值一律映射
  既有令牌——`--bg-mask` 替 `rgba(0,0,0,.55)`、`--z-popup` 替 `z-index:9`、
  `--white` 替 `#fff`、复用 `.sec-added` 类替新写一份 `rgba(var(--design-primary-rgb...))`。
  注意 audit 的 rgba 计的是 **occurrences 不是 kinds**，同值复用也会 +1。
- **压缩产物校验口径再次确认**：wxml 里事件绑定被编译成 `bindtap="{{p}}"`/`{{ac}}`
  （原函数名消失），验证要看「两个 cover-add 节点都在」+「catchtouchmove ×2」+
  「用户可见串」；JS 侧用 API 名（previewImage/cropScale/uploadDynamicImage）。
- **safe-delete 规避有效**：构建前 `mv dist/build/{h5,mp-weixin}` 到 /tmp，uni build 无需清理
  assets（128 文件 >50 阈值），H5/MP 均一次 DONE，未再触发拦截。
