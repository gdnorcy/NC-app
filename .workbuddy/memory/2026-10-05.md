## 多项选择同步 + 五组件对标站精读复刻（commit 2e3f26b）

**1. 多项选择（checkbox）**：实测 schema 与 radio 完全同构（styleRows/colorRows 逐 key 比对零差异），
本轮 radio 的排布优化天然生效。加单测锁死全量同构 + 默认值一致，防「改 radio 忘 checkbox」漂移。

**2. 五组件精读**（用户 Chrome 登录态 `agent-browser open --profile Default --headed`，
对标站 el-radio 真实鼠标点击无效，必须 `el.dispatchEvent(new MouseEvent('click',{bubbles:true}))`）：
精读文档 `docs/对标截图/超级表单/五组件互动逻辑精读.md`，截图 ew-select-*/ew-date-*/ew-time-*/ew-location-*/ew-carplate-*。

关键实测结论：
- select：风格只有框(box1)/线(line)两档（不是三档）；预设类型=省市区/日期时「添加选项」区整块消失；
  下拉框级数默认三级，选项区 tab 数随级数变（一级/二级/三级下拉选项）
- date：内容类型=单个日期/日期范围；「同步生日」仅在单个日期时显示（范围模式整行消失）
- time：时间点/时间段，无其他联动；时间段画布是 el-date-editor--timerange
- location：定位点/点到点；风格三档框1/框2/线
- carplate：面板只有标题+必填（无 placeholder/只读/内容校验）；画布 8 格分位输入；风格仅框一档

**3. 代码修正**：
- select boxLine s1/s2/s3 → box1/line；styleVariant 显式分派（s3≙线，s1/s2≙框，存量兼容）
- location boxLine → box1/box2/line；carplate boxLine → 仅 box（存量 line 仍渲染线风格不丢样）
- carplate 渲染改 8 格分位输入（值=完整车牌字符串，plateCellOf/setPlateCell 分位读写）
- date/time 范围渲染 = 双 input + `~`，值存 'start~end' 字符串（rangePartOf/setRangePart，旧数据天然兼容）
- sfv-box/sfv-line 消费列表补 .sf-plate/.cmpv-plate（审计死参数修复）
- 设计器：date 同步生日加 v-if（范围时隐藏）；time 文案「单个时间」→「时间点」；carplate 面板删 placeholder 行
