- 首页引导文案按登录态切换：「三步完成…」/「登录后三步完成…」（home.vue 新增 `hasLogin` + `refreshLoginFlag()`，onMounted/onShow 刷新）。
- 登录后链路：`login.vue` 的 `isNew || !hasCard` → reLaunch('/pages/card/create')；否则走 redirect → 新建/编辑都能回原位。

## 真机首页空白 = 用户没租户归属（`04777f0`）
- 现象：真机扫码首页一片空白。排查：首页装修配置**存在**（tenant_page_design id=1, tenant_id=1, page_type='home', is_home=1, 7724B）；真机登录建的真实用户 #99057（openid `oIXkh0…`）**customer_id/enterprise_id 全空** → 按租户取不到配置 → `designComps` 为空 → 空白。同一根因也解释了分销「未入驻企业」、人脉库「未入驻任何客户」、集市异常。
- 修：① 后端 `/auth/wx-login` 租户兜底 `const bindTid = Number(tid) || Number(config.defaultTenantId || 0)`（单租户部署；多租户平台把 DEFAULT_TENANT_ID 设 0 关闭）；② 前端 `cardApi.wxLogin(code, parentId, tid)` + login.vue 传 `DEFAULT_TENANT_ID`。
- 存量自愈：已给 #99057 手工补绑（建 tenant_enterprises + customer_id=1，enterprise_role 保持 'none' 与后端逻辑一致）；DB 改前已 cp 备份到 /tmp。
- 🔧 验证姿势：后端 token 无签名，可自造 `base64({uid,openid,ts})+'.x'` 直接用 curl 打 `/api/card/design/config` 看是否返回 tenantId=1 的完整配置。
- **元规则：真机「页面空白/无数据」先查登录用户的 `customer_id` 有没有值**——装修配置/分销/集市/人脉库全按租户取数，空租户 = 空页面。
