## 新坑（已提炼进 MEMORY.md）

- 🔴 **写值播种必须留痕**：ALTER TABLE ADD COLUMN「已存在则报错」天然幂等，但 UPDATE 写值
  播种没有——「某列当前是 0 就播种」会被管理员把配置全关后重启又重开。新增 schema_marks 表
  + markApplied/setMark(db, key)。
- 测试基线比对别用 `git stash`：stash 含 server/test 会把测试回退成旧版（用旧口令）→ 6 个
  假失败；只 stash server/src 又让依赖新模块的测试全挂 + OOM(137)。用「全量 stash 基线 +
  逐个对照」确认存量失败。
