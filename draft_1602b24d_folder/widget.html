二、两条入口
入口 A · 分享名片进入 → 名片展示页(home)
他人转发 / 海报 / 小程序码，带场景值 pid 追踪来源，第一屏即对方名片（tp1/tp2 模板 + 点赞收藏 + 语音 + 雷达）

三、主流程（十二步闭环）
1授权登录
wx.login→code2Session→静默；websocket 常连实时未读
2创建名片
姓名/职位/行业必填；语音、相册、公司、地址；公开/私密
3对外展示
多模板切换；信息卡；语音；VIP 徽章
4访客留痕
浏览 hot+1；点赞/收藏/电话/微信/地址全量雷达上报
5名片分发
转发 / 海报 / 小程序码 / 分销海报 canvas 生成
6名片夹
收藏名片管理、分组、快捷联系
7人脉集市
热门 / 附近 LBS；分类；广告轮播；sticky 吸顶
8雷达运营
意向判客、客户列表、打标签、星标、群发、订阅推送
9会员 VIP
等级套餐 join→order→pay；权益：折扣/可收藏数/语音/建群/模板
10分销分佣
直推+间推两级；支付成功自动分账；合伙人等级
11钱包提现
余额三键隔离；手动/自动企业付款，失败回滚
12平台后台
模板元数据、雷达配置、广告、分类、开数授权
四、关键规则
  • 支付回调幂等：订单 status==0 判重，按 type 分发（VIP/模板/合伙人/置顶）后触发分佣 Hook
  • 分佣规则：直推 proportion1 + 间推 proportion2，比例 ≥1 才入账
  • 名片校验：行业、地址未完善则不能对外展示（引导完善）
  • 模板状态机：0 购买 → 1 使用 → 2 已使用；VIP 享受折扣
  • 提现：受 withdrawal_limit 限制；自动企业付款失败回滚
  • 雷达闭环：配置 → 规则 → 事件 → 意向 → 话术 → 推送 → 打标签
