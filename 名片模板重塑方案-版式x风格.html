名片模板重塑方案 · 版式 × 风格

模板的真正差异来自版式结构，颜色只是皮肤 · 现有 3 个模板只是换色，需要重塑

1

问题诊断：现有模板 = 换色皮肤，不是模板

现状（3 个模板）

商务蓝 #1D4E8F / 简约白 #165dff / 租户金 #B8860B
→ 只改 primary 主色 + 背景色
→ 版式、结构、排版 完全一样
→ 本质是 「换色皮肤」，不是模板

➜

模板应该是什么

版式（结构）：头像位置、信息排列、对齐方式不同
风格（视觉）：渐变 / 字体 / 纹理 / 描边 / 圆角
→ 模板 = 版式 × 风格，组合出真正差异
→ 用户换模板 = 名片换一种呈现方式
